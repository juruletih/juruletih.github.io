2Contoh berpandu

Baca setiap langkah bersama sebabnya. Tutup skrin dan cuba tulis semula sendiri.

Contoh A: jadual nilai fungsi kuadratik

Lengkapkan jadual nilai bagi y = x² − 2x untuk x = −1, 0, 1, 2, 3.

  1. x = −1: y = (−1)² − 2(−1) = 3Gantikan x = −1; gunakan kurungan untuk nombor negatif.
  2. x = 0: y = 0² − 2(0) = 0Gantikan x = 0; gunakan kurungan untuk nombor negatif.
  3. x = 1: y = 1² − 2(1) = −1Gantikan x = 1; gunakan kurungan untuk nombor negatif.
  4. x = 2: y = 2² − 2(2) = 0Gantikan x = 2; gunakan kurungan untuk nombor negatif.
  5. x = 3: y = 3² − 2(3) = 3Gantikan x = 3; gunakan kurungan untuk nombor negatif.

Semak: nilai y simetri (3, 0, −1, 0, 3), sesuai dengan bentuk parabola ✓

Contoh B: nilai fungsi dan objek

Diberi f(x) = 3x − 4. Cari f(2) dan nilai x apabila f(x) = 11.

  1. f(2) = 3(2) − 4 = 2Gantikan objek x = 2 untuk dapat imej.
  2. 3x − 4 = 11f(x) = 11 bermaksud imej ialah 11; cari objek.
  3. 3x = 15Tambah 4 pada kedua-dua belah.
  4. x = 5Bahagi dengan 3.

Semak: f(5) = 15 − 4 = 11 ✓

3Contoh separa siap

Langkah bergaris putus-putus kosong. Tulis langkah itu di kertas dahulu, kemudian tekan "Lihat langkah". Bilangan langkah kosong bertambah.

1. Lengkapkan jadual nilai bagi y = 2x² untuk x = −2, −1, 0, 1, 2. 1 langkah kosong

  1. x = −2: y = 2(−2)² = 8Gantikan x = −2; gunakan kurungan untuk nombor negatif.
  2. x = −1: y = 2(−1)² = 2Gantikan x = −1; gunakan kurungan untuk nombor negatif.
  3. x = 0: y = 2(0)² = 0Gantikan x = 0; gunakan kurungan untuk nombor negatif.
  4. x = 1: y = 2(1)² = 2Gantikan x = 1; gunakan kurungan untuk nombor negatif.
  5. Lihat langkahx = 2: y = 2(2)² = 8Gantikan x = 2; gunakan kurungan untuk nombor negatif.

2. Diberi f(x) = 5 − 2x. Cari f(−3) dan nilai x apabila f(x) = 1. 2 langkah kosong

  1. f(−3) = 5 − 2(−3)Gantikan dengan kurungan.
  2. = 5 + 6 = 11Negatif × negatif = positif.
  3. Lihat langkah5 − 2x = 1 → 2x = 4Susun semula.
  4. Lihat langkahx = 2Bahagi dengan 2.

3. Titik (2, k) terletak pada graf y = x² + 3. Cari k. 2 langkah kosong

  1. Titik pada graf memenuhi persamaan grafKoordinat titik boleh digantikan ke dalam persamaan.
  2. Lihat langkahk = 2² + 3Gantikan x = 2, y = k.
  3. Lihat langkahk = 7Kira.

4. Lengkapkan jadual nilai bagi y = x³ untuk x = −2, −1, 0, 1, 2. 3 langkah kosong

  1. x = −2: y = (−2)³ = −8Gantikan x = −2; gunakan kurungan untuk nombor negatif.
  2. x = −1: y = (−1)³ = −1Gantikan x = −1; gunakan kurungan untuk nombor negatif.
  3. Lihat langkahx = 0: y = (0)³ = 0Gantikan x = 0; gunakan kurungan untuk nombor negatif.
  4. Lihat langkahx = 1: y = (1)³ = 1Gantikan x = 1; gunakan kurungan untuk nombor negatif.
  5. Lihat langkahx = 2: y = (2)³ = 8Gantikan x = 2; gunakan kurungan untuk nombor negatif.

5Cari silap

Kesilapan ini paling kerap berlaku dalam bab ini. Mengenal pasti silap orang lain membantu anda mengelakkannya.

1.
Cari nilai y = x² apabila x = −3. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Tanpa kurungan, −3² bermaksud −(3²). Gantikan nombor negatif dalam kurungan.

  1. y = (−3)²
  2. y = 9
2.
Diberi f(x) = 2x + 1. Cari x apabila f(x) = 9. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

f(x) = 9 memberi imej, bukan objek. Selesaikan persamaan untuk mencari x.

  1. 2x + 1 = 9
  2. 2x = 8, x = 4
3.
Lengkapkan jadual y = 3 − x untuk x = −2. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Tolak negatif bermaksud tambah.

  1. y = 3 + 2 = 5
4.
Adakah hubungan {(1, a), (2, a), (3, b)} suatu fungsi? Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Syarat fungsi: setiap OBJEK hanya ada satu imej. Dua objek boleh berkongsi imej yang sama.

  1. Setiap objek mempunyai tepat satu imej
  2. Hubungan banyak kepada satu ialah fungsi
5.
Plot titik (−2, 3). Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Koordinat-x ditulis dahulu dan sentiasa mengufuk; negatif bermaksud ke kiri.

  1. Koordinat-x = −2: bergerak 2 unit ke kiri
  2. Koordinat-y = 3: bergerak 3 unit ke atas
