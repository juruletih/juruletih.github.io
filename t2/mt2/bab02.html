Nota

2.1 Kembangan

Kembangan ialah proses mendarab setiap sebutan dalam kurungan supaya kurungan dapat dikeluarkan.

  • a(b + c) = ab + ac
  • (a + b)(c + d) = ac + ad + bc + bd
  • (a + b)² = a² + 2ab + b²
  • (a − b)² = a² − 2ab + b²
  • (a + b)(a − b) = a² − b²

Contoh 1. (x + 3)(x + 5) = x² + 5x + 3x + 15 = x² + 8x + 15

Contoh 2. Permudahkan (x + 2)² − x(x + 1).
= x² + 4x + 4 − x² − x = 3x + 4

Awas miskonsepsi: (x + 3)² bukan x² + 9. Sebutan tengah 2(x)(3) = 6x mesti ada.

2.2 Pemfaktoran

Pemfaktoran ialah songsangan kembangan: tulis ungkapan sebagai hasil darab faktor-faktornya.

  1. Faktor sepunya: 6x + 9 = 3(2x + 3)
  2. Beza dua kuasa dua: x² − 9 = (x + 3)(x − 3)
  3. Trinomial x² + bx + c: cari dua nombor yang hasil darabnya c dan hasil tambahnya b. x² + 7x + 12: 3 × 4 = 12, 3 + 4 = 7 → (x + 3)(x + 4)
  4. Kumpulan sebutan: ax + ay + bx + by = a(x + y) + b(x + y) = (a + b)(x + y)

Semak jawapan: kembangkan semula faktor anda; mesti dapat ungkapan asal.

2.3 Ungkapan Algebra dan Pecahan Algebra

Tambah/tolak: samakan penyebut dahulu. 1/x + 1/(2x) = 2/(2x) + 1/(2x) = 3/(2x)

Darab: faktorkan, kemudian batalkan faktor sepunya. (6x/5) × (10/(3x²)) = 4/x

Bahagi: darab dengan salingan pecahan kedua. (x/3) ÷ (x²/6) = (x/3) × (6/x²) = 2/x

Awas miskonsepsi: (x + 2)/2 bukan x + 1 jika anda “batalkan” 2 sahaja. Hanya faktor boleh dibatalkan: (x + 2)/2 = x/2 + 1.

Latihan

Cuba dahulu di kertas. Tekan "Semak jawapan" selepas anda cuba.

  1. Kembangkan 4(2x − 3).2.1.2 / TP1
    Semak jawapan
    8x − 12
  2. Kembangkan (x − 4)(x + 6).2.1.2 / TP2
    Semak jawapan
    x² + 2x − 24
  3. Kembangkan (2x − 1)².2.1.2 / TP3
    Semak jawapan
    4x² − 4x + 1
  4. Permudahkan (x + 5)(x − 5) − (x − 2)².2.1.3 / TP3
    Semak jawapan
    x² − 25 − (x² − 4x + 4) = 4x − 29
  5. Faktorkan selengkapnya: (a) 12x² − 8x (b) x² − 49 (c) x² − x − 62.2.2 / TP3
    Semak jawapan
    (a) 4x(3x − 2) (b) (x + 7)(x − 7) (c) (x − 3)(x + 2)
  6. Faktorkan 2x² + 5x + 3.2.2.2 / TP4
    Semak jawapan
    (2x + 3)(x + 1)
  7. Ungkapkan sebagai satu pecahan termudah: 2/(3x) + 5/(6x).2.3.1 / TP3
    Semak jawapan
    4/(6x) + 5/(6x) = 9/(6x) = 3/(2x)
  8. Permudahkan (x² − 4)/(3x + 6).2.3.2 / TP4
    Semak jawapan
    (x + 2)(x − 2) / 3(x + 2) = (x − 2)/3
  9. (KBAT) Sebuah taman segi empat sama bersisi x m dibesarkan dengan menambah 3 m pada setiap sisi. Tunjukkan bahawa pertambahan luas ialah (6x + 9) m², kemudian faktorkannya.2.1.4, 2.2.3 / TP5
    Semak jawapan
    (x + 3)² − x² = x² + 6x + 9 − x² = 6x + 9 = 3(2x + 3)
  10. (KBAT) Luas sebuah segi empat tepat ialah (x² + 5x + 6) cm² dan lebarnya (x + 2) cm. Cari panjangnya dan perimeter dalam sebutan x.2.2.3 / TP6
    Semak jawapan
    Panjang = x + 3 cm; perimeter = 2(x + 3 + x + 2) = (4x + 10) cm
