2Contoh berpandu

Baca setiap langkah bersama sebabnya. Tutup skrin dan cuba tulis semula sendiri.

Contoh A: kembangan dua kurungan

Kembangkan (x + 4)(x − 3).

  1. x × x = x²Darab sebutan pertama dengan sebutan pertama.
  2. x × (−3) = −3xSebutan luar: x darab sebutan kedua kurungan kedua.
  3. 4 × x = 4xSebutan dalam: nombor kurungan pertama darab x.
  4. 4 × (−3) = −12Sebutan akhir: darab dua nombor, ikut hukum tanda.
  5. = x² + x − 12Gabung sebutan serupa: −3x + 4x = x.

Semak dengan x = 1: (5)(−2) = −10 dan 1 + 1 − 12 = −10 ✓

Contoh B: pemfaktoran x² + bx + c

Faktorkan x² + 7x + 12.

  1. Cari dua nombor: hasil darab 12, hasil tambah 7x² + bx + c = (x + p)(x + q) dengan p × q = c dan p + q = b.
  2. Pasangan faktor 12: 1 × 12, 2 × 6, 3 × 4Senaraikan pasangan faktor; kemudian pilih tanda.
  3. 3 × 4 = 12 dan 3 + 4 = 7Pilih pasangan yang memberi hasil tambah betul.
  4. = (x + 3)(x + 4)Tulis dua faktor.
  5. Semak: kembangkan (x + 3)(x + 4) = x² + 7x + 12 ✓Sentiasa semak faktor dengan kembangan.

3Contoh separa siap

Langkah bergaris putus-putus kosong. Tulis langkah itu di kertas dahulu, kemudian tekan "Lihat langkah". Bilangan langkah kosong bertambah.

1. Kembangkan (x + 5)(x − 2). 1 langkah kosong

  1. x × x = x²Darab sebutan pertama dengan sebutan pertama.
  2. x × (−2) = −2xSebutan luar: x darab sebutan kedua kurungan kedua.
  3. 5 × x = 5xSebutan dalam: nombor kurungan pertama darab x.
  4. 5 × (−2) = −10Sebutan akhir: darab dua nombor, ikut hukum tanda.
  5. Lihat langkah= x² + 3x − 10Gabung sebutan serupa: −2x + 5x = 3x.

2. Faktorkan x² − x − 20. 2 langkah kosong

  1. Cari dua nombor: hasil darab −20, hasil tambah −1x² + bx + c = (x + p)(x + q) dengan p × q = c dan p + q = b.
  2. Pasangan faktor 20: 1 × 20, 2 × 10, 4 × 5Senaraikan pasangan faktor; kemudian pilih tanda.
  3. (−5) × 4 = −20 dan (−5) + 4 = −1Pilih pasangan yang memberi hasil tambah betul.
  4. Lihat langkah= (x − 5)(x + 4)Tulis dua faktor.
  5. Lihat langkahSemak: kembangkan (x − 5)(x + 4) = x² − x − 20 ✓Sentiasa semak faktor dengan kembangan.

3. Faktorkan x² + 9x + 14. 3 langkah kosong

  1. Cari dua nombor: hasil darab 14, hasil tambah 9x² + bx + c = (x + p)(x + q) dengan p × q = c dan p + q = b.
  2. Pasangan faktor 14: 1 × 14, 2 × 7Senaraikan pasangan faktor; kemudian pilih tanda.
  3. Lihat langkah2 × 7 = 14 dan 2 + 7 = 9Pilih pasangan yang memberi hasil tambah betul.
  4. Lihat langkah= (x + 2)(x + 7)Tulis dua faktor.
  5. Lihat langkahSemak: kembangkan (x + 2)(x + 7) = x² + 9x + 14 ✓Sentiasa semak faktor dengan kembangan.

4. Permudahkan (x² − 9)/(x + 3). 2 langkah kosong

  1. x² − 9 = x² − 3²Kenal pasti beza dua kuasa dua.
  2. = (x + 3)(x − 3)a² − b² = (a + b)(a − b).
  3. (x + 3)(x − 3) / (x + 3)Tulis semula pecahan dengan pengangka yang sudah difaktorkan.
  4. Lihat langkahBatalkan faktor sepunya (x + 3)Hanya FAKTOR (darab) boleh dibatalkan, bukan sebutan (tambah).
  5. Lihat langkah= x − 3Jawapan dalam bentuk termudah.

5Cari silap

Kesilapan ini paling kerap berlaku dalam bab ini. Mengenal pasti silap orang lain membantu anda mengelakkannya.

1.
Kembangkan (x + 3)². Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

(x + 3)² bermaksud (x + 3)(x + 3). Kuasa tidak boleh diagihkan kepada setiap sebutan; sebutan tengah 6x tertinggal.

  1. (x + 3)² = (x + 3)(x + 3)
  2. = x² + 3x + 3x + 9
  3. = x² + 6x + 9
2.
Permudahkan (x + 5)/5. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Hanya faktor boleh dibatalkan. Dalam x + 5, nombor 5 ditambah, bukan didarab.

  1. 5 ialah sebutan, bukan faktor bagi pengangka
  2. (x + 5)/5 = x/5 + 1
3.
Faktorkan 6x + 9. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Setiap sebutan mesti dibahagi dengan FSTB. Semak: 3(2x + 3) = 6x + 9 ✓.

  1. 6x ÷ 3 = 2x dan 9 ÷ 3 = 3
  2. 6x + 9 = 3(2x + 3)
4.
Kembangkan −2(x − 4). Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Negatif × negatif = positif.

  1. −2 × (−4) = 8
  2. = −2x + 8
5.
Faktorkan x² − 16. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Semak: (x − 4)(x − 4) = x² − 8x + 16, bukan x² − 16.

  1. a² − b² = (a + b)(a − b)
  2. = (x + 4)(x − 4)
