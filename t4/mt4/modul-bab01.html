1Semak prasyarat

Jawab 4 soalan ini dahulu. Jika salah 2 atau lebih, buat Bank Latihan Tingkatan 2 Bab 2: Pemfaktoran dan Pecahan Algebra sebelum meneruskan.

1.
Kembangkan (x + 3)(x − 5).
Penyelesaian
  1. (x + 3)(x − 5) = x² − 5x + 3x − 15
  2. = x² − 2x − 15
2.
Faktorkan x² − 7x + 12.
Penyelesaian
  1. Cari dua nombor: hasil darab 12, hasil tambah −7 → −3 dan −4
  2. (x − 3)(x − 4)
3.
Nilai 2x² − 3 apabila x = −4 ialah
Penyelesaian
  1. (−4)² = 16 (negatif × negatif = positif)
  2. 2(16) − 3 = 29
4.
Jika (x − 2)(x + 5) = 0, maka
Penyelesaian
  1. Jika hasil darab dua nombor ialah 0, sekurang-kurangnya satu nombor itu ialah 0.
  2. x = 2 atau x = −5

2Contoh berpandu

Baca setiap langkah bersama sebabnya. Tutup skrin dan cuba tulis semula sendiri.

Contoh A: selesaikan persamaan kuadratik

Selesaikan x² − x = 12.

  1. x² − x − 12 = 0Pindahkan semua sebutan ke sebelah kiri supaya sebelah kanan ialah 0 (bentuk am).
  2. Dua nombor: hasil darab −12, hasil tambah −1 → −4 dan 3Faktor x² + bx + c memerlukan dua nombor dengan hasil darab c dan hasil tambah b.
  3. (x − 4)(x + 3) = 0Tulis faktor menggunakan dua nombor itu.
  4. x − 4 = 0 atau x + 3 = 0Hasil darab sifar: sekurang-kurangnya satu faktor ialah 0.
  5. x = 4 atau x = −3Selesaikan setiap persamaan linear.

Semak: 4² − 4 = 12 ✓ dan (−3)² − (−3) = 9 + 3 = 12 ✓

Contoh B: paksi simetri dan titik pusingan

Diberi f(x) = x² − 6x + 5. Cari paksi simetri dan titik pusingan graf.

  1. a = 1, b = −6, c = 5Banding dengan ax² + bx + c; ambil tanda bersama nombor.
  2. x = −b/(2a) = −(−6)/(2 × 1) = 3Paksi simetri melalui titik pusingan, x = −b/(2a).
  3. f(3) = (3)² − 6(3) + 5 = −4Gantikan nilai x paksi simetri ke dalam f(x) untuk dapat koordinat-y.
  4. a > 0 → graf ∪, titik minimumTanda a menentukan arah bukaan graf.
  5. Titik minimum (3, −4); paksi simetri x = 3Tulis jawapan lengkap.

Semak: f(2) = f(4) = −3, jadi graf simetri pada x = 3 ✓

3Contoh separa siap

Langkah bergaris putus-putus kosong. Tulis langkah itu di kertas dahulu, kemudian tekan "Lihat langkah". Bilangan langkah kosong bertambah.

1. Selesaikan x² − 5x = 6. 1 langkah kosong

  1. x² − 5x − 6 = 0Pindahkan semua sebutan ke sebelah kiri supaya sebelah kanan ialah 0 (bentuk am).
  2. Dua nombor: hasil darab −6, hasil tambah −5 → −6 dan 1Faktor x² + bx + c memerlukan dua nombor dengan hasil darab c dan hasil tambah b.
  3. (x − 6)(x + 1) = 0Tulis faktor menggunakan dua nombor itu.
  4. x − 6 = 0 atau x + 1 = 0Hasil darab sifar: sekurang-kurangnya satu faktor ialah 0.
  5. Lihat langkahx = 6 atau x = −1Selesaikan setiap persamaan linear.

2. Selesaikan x² + 2x = 24. 2 langkah kosong

  1. x² + 2x − 24 = 0Pindahkan semua sebutan ke sebelah kiri supaya sebelah kanan ialah 0 (bentuk am).
  2. Dua nombor: hasil darab −24, hasil tambah 2 → −4 dan 6Faktor x² + bx + c memerlukan dua nombor dengan hasil darab c dan hasil tambah b.
  3. (x − 4)(x + 6) = 0Tulis faktor menggunakan dua nombor itu.
  4. Lihat langkahx − 4 = 0 atau x + 6 = 0Hasil darab sifar: sekurang-kurangnya satu faktor ialah 0.
  5. Lihat langkahx = 4 atau x = −6Selesaikan setiap persamaan linear.

3. Selesaikan x² − 3x = 10. 3 langkah kosong

  1. x² − 3x − 10 = 0Pindahkan semua sebutan ke sebelah kiri supaya sebelah kanan ialah 0 (bentuk am).
  2. Dua nombor: hasil darab −10, hasil tambah −3 → −5 dan 2Faktor x² + bx + c memerlukan dua nombor dengan hasil darab c dan hasil tambah b.
  3. Lihat langkah(x − 5)(x + 2) = 0Tulis faktor menggunakan dua nombor itu.
  4. Lihat langkahx − 5 = 0 atau x + 2 = 0Hasil darab sifar: sekurang-kurangnya satu faktor ialah 0.
  5. Lihat langkahx = 5 atau x = −2Selesaikan setiap persamaan linear.

4. Diberi f(x) = x² − 4x − 5. Cari paksi simetri dan titik pusingan graf. 2 langkah kosong

  1. a = 1, b = −4, c = −5Banding dengan ax² + bx + c; ambil tanda bersama nombor.
  2. x = −b/(2a) = −(−4)/(2 × 1) = 2Paksi simetri melalui titik pusingan, x = −b/(2a).
  3. f(2) = (2)² − 4(2) − 5 = −9Gantikan nilai x paksi simetri ke dalam f(x) untuk dapat koordinat-y.
  4. Lihat langkaha > 0 → graf ∪, titik minimumTanda a menentukan arah bukaan graf.
  5. Lihat langkahTitik minimum (2, −9); paksi simetri x = 2Tulis jawapan lengkap.

5. Diberi f(x) = −x² + 2x + 7. Cari paksi simetri dan titik pusingan graf. 4 langkah kosong

  1. a = −1, b = 2, c = 7Banding dengan ax² + bx + c; ambil tanda bersama nombor.
  2. Lihat langkahx = −b/(2a) = −(2)/(2 × (−1)) = 1Paksi simetri melalui titik pusingan, x = −b/(2a).
  3. Lihat langkahf(1) = −(1)² + 2(1) + 7 = 8Gantikan nilai x paksi simetri ke dalam f(x) untuk dapat koordinat-y.
  4. Lihat langkaha < 0 → graf ∩, titik maksimumTanda a menentukan arah bukaan graf.
  5. Lihat langkahTitik maksimum (1, 8); paksi simetri x = 1Tulis jawapan lengkap.

5Cari silap

Kesilapan ini paling kerap berlaku dalam bab ini. Mengenal pasti silap orang lain membantu anda mengelakkannya.

1.
Selesaikan x² = 5x. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Membahagi dengan x menghilangkan punca x = 0. Pindahkan semua sebutan ke kiri, kemudian faktorkan.

  1. x² − 5x = 0
  2. x(x − 5) = 0
  3. x = 0 atau x = 5
2.
Selesaikan x² − 3x − 4 = 0. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Jika x − 4 = 0, maka x = 4 (bukan −4). Tanda bertukar apabila sebutan dipindahkan.

  1. x − 4 = 0 atau x + 1 = 0
  2. x = 4 atau x = −1
3.
Lebar sebuah segi empat tepat ialah x cm dan panjangnya (x + 5) cm. Luasnya 36 cm². Cari x. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Hukum hasil darab sifar hanya berlaku apabila sebelah kanan ialah 0. 36 bukan 0, jadi tulis bentuk am dahulu.

  1. x² + 5x − 36 = 0
  2. (x − 4)(x + 9) = 0
  3. x = 4 atau x = −9; lebar positif, x = 4
4.
Cari titik minimum bagi f(x) = x² − 4x + 9. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Paksi simetri ialah x = −b/(2a). Tanda negatif di hadapan b tertinggal.

  1. x = −b/(2a) = −(−4)/2 = 2
  2. f(2) = 4 − 8 + 9 = 5
  3. Titik minimum (2, 5)
5.
Diberi f(x) = x² + 2x + 7. Cari f(−3). Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

(−3)² bermaksud (−3) × (−3), hasilnya positif. Pada kalkulator, taip (−3)² dengan kurungan.

  1. (−3)² = (−3) × (−3) = 9
  2. = 9 − 6 + 7
  3. = 10

  2. = 8x² + 6x − 9

Penyelesaian

  2. = (x − 5)(x + 8)
3.

Penyelesaian
  1. x membatalkan x
  2. 4/5
