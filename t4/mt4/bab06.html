Bab 6: Ketaksamaan Linear dalam Dua Pemboleh Ubah

  • mewakilkan situasi sebagai sistem ketaksamaan linear, melorek rantau dan menyelesaikan masalah (SP 6.2.1–6.2.4)

Slaid

Buka slaid

Slaid penuh skrin. Guna anak panah atau leret jari. Boleh dicetak.

Nota

6.1 Ketaksamaan Linear dalam Dua Pemboleh Ubah

Ketaksamaan linear dua pemboleh ubah, cth. 2x + 5y ≤ 50, y > 2x + 1.

Frasa: "tidak melebihi" / "selebih-lebihnya" → ≤; "sekurang-kurangnya" / "tidak kurang daripada" → ≥; "melebihi" → >; "kurang daripada" → <.

Garis sempadan: garis penuh bagi ≤ atau ≥ (titik pada garis termasuk); garis putus-putus bagi < atau >.

Rantau: bagi y > mx + c, lorek di atas garis; bagi y < mx + c, di bawah. Bagi x > h, sebelah kanan garis x = h.

Uji titik: gantikan koordinat ke dalam ketaksamaan. Cth. (0, 3) dalam y > 2x + 1 kerana 3 > 1.

6.2 Sistem Ketaksamaan Linear

Sistem ketaksamaan linear: dua atau lebih ketaksamaan yang mesti dipenuhi serentak.

Rantau penyelesaian ialah kawasan persilangan (bertindih) rantau semua ketaksamaan.

Contoh. x ≥ 0, y ≥ 0, x + y ≤ 4 → segi tiga dengan bucu (0, 0), (4, 0), (0, 4).

Dalam masalah, nilai maksimum atau minimum sesuatu ungkapan (cth. x + y) berlaku pada salah satu bucu rantau. Jika pemboleh ubah mewakili bilangan barang, hanya titik integer diterima.

Latihan

Cuba dahulu di kertas. Tekan "Semak jawapan" selepas anda cuba.

  1. Pen RM2 sebatang (x batang) dan buku RM5 sebuah (y buah). Jumlah perbelanjaan tidak melebihi RM50. Tulis ketaksamaan.6.1.1 / TP1
    Semak jawapan
    2x + 5y ≤ 50
  2. Bilangan murid lelaki (x) sekurang-kurangnya dua kali bilangan murid perempuan (y). Tulis ketaksamaan.6.1.1 / TP2
    Semak jawapan
    x ≥ 2y
  3. Tentukan sama ada (0, 3), (1, 2) dan (2, 5) memuaskan y > 2x + 1.6.1.2 / TP3
    Semak jawapan
    (0, 3) ya; (1, 2) tidak; (2, 5) tidak (pada garis)
  4. Lorek rantau y ≥ x − 2. Nyatakan jenis garis sempadan.6.1.3 / TP3
    Semak jawapan
    Di atas garis, garis penuh
  5. Tulis ketaksamaan bagi rantau di bawah garis yang melalui (0, 4) dan (2, 0), termasuk garis.6.1.3 / TP4
    Semak jawapan
    y ≤ −2x + 4
  6. Kedai menjual x kek dan y roti. Jumlah tidak melebihi 50 dan kek sekurang-kurangnya 10. Tulis sistem ketaksamaan.6.2.1 / TP2
    Semak jawapan
    x + y ≤ 50, x ≥ 10
  7. Lorek rantau x ≥ 0, y ≥ 0, x + y ≤ 4 dan hitung luasnya.6.2.3 / TP3
    Semak jawapan
    Segi tiga; luas 8 unit²
  8. Senaraikan semua titik integer dalam rantau x ≥ 0, y ≥ 0, x + y ≤ 2.6.2.2 / TP4
    Semak jawapan
    (0,0), (1,0), (2,0), (0,1), (1,1), (0,2)
  9. (KBAT) Bagi rantau y ≥ x, y ≤ 6, x ≥ 2, cari nilai maksimum x + y.6.2.4 / TP5
    Semak jawapan
    Bucu (2,2), (2,6), (6,6); maksimum 12
  10. (KBAT) Ahmad membeli x buku (RM8) dan y pen (RM3) dengan tidak lebih RM40, sekurang-kurangnya 2 buku, dan bilangan pen tidak kurang daripada bilangan buku. Cari bilangan maksimum barang.6.2.4 / TP6
    Semak jawapan
    x = 2, y = 8 → 10 barang
