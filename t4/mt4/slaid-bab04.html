4.1 Persilangan Set

A ∩ B ialah set unsur yang terdapat dalam A dan B. Pada gambar rajah Venn, kawasan bertindih.

Perwakilan: perihalan (cth. "gandaan 3 dan gandaan 4"), tatatanda (senarai atau pembina set), dan gambar rajah Venn.

(A ∩ B)′ ialah unsur dalam ξ yang bukan dalam A ∩ B. Jika A ⊂ B, maka A ∩ B = A.

Contoh 1. A = {2, 4, 6, 8}, B = {1, 2, 3, 4} → A ∩ B = {2, 4}.

4.2 Kesatuan Set

A ∪ B ialah set unsur dalam A atau B atau kedua-duanya (setiap unsur ditulis sekali sahaja).

n(A ∪ B) = n(A) + n(B) − n(A ∩ B). (A ∪ B)′ ialah unsur yang tidak dalam A dan tidak dalam B.

Jika B ⊂ A, maka A ∪ B = A.

Contoh 2. n(A) = 15, n(B) = 10, n(A ∩ B) = 4 → n(A ∪ B) = 21.

4.3 Gabungan Operasi Set

Lakukan operasi dalam kurungan dahulu, kemudian dari kiri ke kanan.

Contoh 3. ξ = {1, 2, …, 12}, A = {1, 2, 3, 4, 5, 6}, B = {4, 5, 6, 7, 8}, C = {6, 8, 10, 12}. B ∪ C = {4, 5, 6, 7, 8, 10, 12}, maka A ∩ (B ∪ C) = {4, 5, 6}.

A ∩ B′ = unsur A yang bukan dalam B. Untuk masalah, lukis gambar rajah Venn dan isi kawasan paling dalam dahulu.
