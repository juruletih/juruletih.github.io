Nota

2.1 Asas Nombor

Nombor dalam asas n (n < 10) menggunakan digit 0, 1, 2, …, n − 1 sahaja. Contoh: asas 2 → 0, 1; asas 5 → 0, 1, 2, 3, 4.

Nilai tempat ialah kuasa asas: … n³, n², n¹, n⁰ (dari kiri ke kanan). Nilai digit = digit × nilai tempat. Nilai nombor = hasil tambah semua nilai digit.

Contoh 1. 2314₅ = 2(5³) + 3(5²) + 1(5¹) + 4(5⁰) = 250 + 75 + 5 + 4 = 334₁₀. Nilai digit 3 ialah 3 × 25 = 75.

Asas 10 → asas n: bahagi berulang dengan n; baca baki dari bawah ke atas. 45₁₀ → asas 2: baki 1, 0, 1, 1, 0, 1 → 101101₂.

Asas m → asas n: tukar kepada asas 10 dahulu, kemudian ke asas n. Bagi asas 2 ↔ asas 8, kumpulkan 3 digit asas 2 (8 = 2³).

Tambah/tolak: susun ikut nilai tempat. Apabila hasil tambah ≥ n, bawa 1 ke lajur seterusnya; semasa menolak, pinjam 1 = n daripada lajur kiri.

Contoh 2. 1101₂ + 111₂ = 10100₂ (13 + 7 = 20). Kalkulator hanya untuk menyemak jawapan.

Latihan

Cuba dahulu di kertas. Tekan "Semak jawapan" selepas anda cuba.

  1. Senaraikan digit yang digunakan dalam asas 6.2.1.1 / TP1
    Semak jawapan
    0, 1, 2, 3, 4, 5
  2. Nyatakan nilai tempat dan nilai digit bagi digit 3 dalam 2314₅.2.1.1 / TP2
    Semak jawapan
    Nilai tempat 5² = 25; nilai digit 75
  3. Tukar 1011₂ kepada asas 10.2.1.2 / TP2
    Semak jawapan
    11
  4. Tukar 45₁₀ kepada asas 2.2.1.2 / TP3
    Semak jawapan
    101101₂
  5. Tukar 213₄ kepada asas 8.2.1.2 / TP3
    Semak jawapan
    213₄ = 39₁₀ = 47₈
  6. Hitung 1101₂ + 111₂.2.1.3 / TP3
    Semak jawapan
    10100₂
  7. Hitung 342₅ − 143₅.2.1.3 / TP4
    Semak jawapan
    144₅
  8. Diberi 23ₙ = 17₁₀. Cari nilai n.2.1.4 / TP4
    Semak jawapan
    2n + 3 = 17 → n = 7
  9. (KBAT) Susun 110110₂, 67₈, 212₄ dan 201₅ mengikut tertib menaik.2.1.4 / TP5
    Semak jawapan
    212₄ (38), 201₅ (51), 110110₂ (54), 67₈ (55)
  10. (KBAT) Nombor dua digit ab₈. Apabila digitnya diterbalikkan, nilainya bertambah 21₁₀. Cari b − a dan berikan satu contoh nombor itu.2.1.4 / TP6
    Semak jawapan
    7(b − a) = 21 → b − a = 3; cth. 14₈ dan 41₈
