Nota

4.1 Persilangan Set

A ∩ B ialah set unsur yang terdapat dalam A dan B. Pada gambar rajah Venn, kawasan bertindih.

Perwakilan: perihalan (cth. "gandaan 3 dan gandaan 4"), tatatanda (senarai atau pembina set), dan gambar rajah Venn.

(A ∩ B)′ ialah unsur dalam ξ yang bukan dalam A ∩ B. Jika A ⊂ B, maka A ∩ B = A.

Contoh 1. A = {2, 4, 6, 8}, B = {1, 2, 3, 4} → A ∩ B = {2, 4}.

4.2 Kesatuan Set

A ∪ B ialah set unsur dalam A atau B atau kedua-duanya (setiap unsur ditulis sekali sahaja).

n(A ∪ B) = n(A) + n(B) − n(A ∩ B). (A ∪ B)′ ialah unsur yang tidak dalam A dan tidak dalam B.

Jika B ⊂ A, maka A ∪ B = A.

Contoh 2. n(A) = 15, n(B) = 10, n(A ∩ B) = 4 → n(A ∪ B) = 21.

4.3 Gabungan Operasi Set

Lakukan operasi dalam kurungan dahulu, kemudian dari kiri ke kanan.

Contoh 3. ξ = {1, 2, …, 12}, A = {1, 2, 3, 4, 5, 6}, B = {4, 5, 6, 7, 8}, C = {6, 8, 10, 12}. B ∪ C = {4, 5, 6, 7, 8, 10, 12}, maka A ∩ (B ∪ C) = {4, 5, 6}.

A ∩ B′ = unsur A yang bukan dalam B. Untuk masalah, lukis gambar rajah Venn dan isi kawasan paling dalam dahulu.

Latihan

Cuba dahulu di kertas. Tekan "Semak jawapan" selepas anda cuba.

  1. A = {2, 4, 6, 8}, B = {1, 2, 3, 4}. Senaraikan A ∩ B dan A ∪ B.4.1.1 / TP1
    Semak jawapan
    {2, 4}; {1, 2, 3, 4, 6, 8}
  2. P = {gandaan 3 kurang daripada 20}, Q = {gandaan 4 kurang daripada 20}. Senaraikan P ∩ Q.4.1.1 / TP2
    Semak jawapan
    {12}
  3. ξ = {1, 2, …, 10}, A = {nombor genap}, B = {gandaan 3}. Cari n((A ∩ B)′).4.1.2 / TP3
    Semak jawapan
    9
  4. ξ = {1, 2, …, 10}, A = {1, 2, 3, 4}, B = {3, 4, 5, 6}. Senaraikan (A ∪ B)′.4.2.2 / TP2
    Semak jawapan
    {7, 8, 9, 10}
  5. n(A) = 15, n(B) = 10 dan n(A ∩ B) = 4. Cari n(A ∪ B).4.2.3 / TP3
    Semak jawapan
    21
  6. Menggunakan A, B, C dalam Contoh 3, senaraikan (A ∩ B) ∪ C dan A ∩ B′.4.3.1 / TP3
    Semak jawapan
    {4, 5, 6, 8, 10, 12}; {1, 2, 3}
  7. Menggunakan set yang sama, senaraikan (A ∪ B ∪ C)′.4.3.2 / TP4
    Semak jawapan
    {9, 11}
  8. Dalam kelas 40 murid, 25 suka bola sepak, 18 suka badminton dan 7 tidak suka kedua-duanya. Berapakah murid suka kedua-duanya?4.1.3 / TP4
    Semak jawapan
    25 + 18 − 33 = 10
  9. (KBAT) n(A) = 12, n(B) = 9, n(ξ) = 18. Cari nilai terkecil dan terbesar yang mungkin bagi n(A ∩ B).4.2.3 / TP5
    Semak jawapan
    Terkecil 3, terbesar 9
  10. (KBAT) n(ξ) = 40, n(A) = 12, n(B) = 15, n(C) = 13, n(A ∩ B) = 5, n(A ∩ C) = 4, n(B ∩ C) = 6, n(A ∩ B ∩ C) = 2. Cari n((A ∪ B ∪ C)′).4.3.3 / TP6
    Semak jawapan
    40 − 27 = 13
