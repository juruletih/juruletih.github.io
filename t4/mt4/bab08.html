Bab 8: Sukatan Serakan Data Tak Terkumpul

Matematik Tingkatan 4 · Nota, latihan dan kuiz

Selepas bab ini, anda boleh

  • menerangkan maksud serakan serta membanding dan mentafsir serakan dua set data daripada plot batang-dan-daun dan plot titik (SP 8.1.1, 8.1.2)
  • menentukan julat, julat antara kuartil, varians dan sisihan piawai serta membina dan mentafsir plot kotak (SP 8.2.1–8.2.3)
  • menentukan kesan perubahan data terhadap serakan, membanding set data dan menyelesaikan masalah (SP 8.2.4–8.2.6)

Slaid

Buka slaid

Slaid penuh skrin. Guna anak panah atau leret jari. Boleh dicetak.

Nota

8.1 Serakan

Serakan ialah ukuran sejauh mana data tersebar. Data yang berkelompok rapat mempunyai serakan kecil (lebih konsisten).

Soalan statistik ialah soalan yang dijawab dengan mengumpul data yang berbeza-beza, cth. "Berapakah masa yang diambil murid Tingkatan 4 untuk ke sekolah?"

Plot titik dan plot batang-dan-daun membantu membandingkan serakan. Dua set data boleh mempunyai min yang sama tetapi serakan berbeza.

Pencilan ialah nilai yang jauh berbeza daripada nilai lain dalam set data.

8.2 Sukatan Serakan

Julat = nilai terbesar − nilai terkecil.

Kuartil: susun data menaik. Q₁ = nilai pada kedudukan ¼(n + 1), Q₃ = nilai pada kedudukan ¾(n + 1). Julat antara kuartil = Q₃ − Q₁.

Varians σ² = Σx²/N − x̄² atau Σ(x − x̄)²/N. Sisihan piawai σ = √varians.

Plot kotak menunjukkan nilai minimum, Q₁, median, Q₃ dan nilai maksimum.

Kesan perubahan data: tambah/tolak k pada setiap data → julat, julat antara kuartil, varians dan sisihan piawai tidak berubah. Darab setiap data dengan k → julat dan σ didarab k, varians didarab k².

Julat dan varians mudah dipengaruhi pencilan; julat antara kuartil kurang dipengaruhi.

Contoh. Data 2, 4, 6, 8: x̄ = 5, varians = (9 + 1 + 1 + 9)/4 = 5, σ = √5 ≈ 2.236.

Latihan

Cuba dahulu di kertas. Tekan "Semak jawapan" selepas anda cuba.

  1. Terangkan maksud serakan dan beri satu contoh soalan statistik.8.1.1 / TP1
    Semak jawapan
    Ukuran sejauh mana data tersebar; cth. masa ke sekolah murid Tingkatan 4
  2. Plot batang-dan-daun: 1 | 2 5 8, 2 | 0 3 3 7, 3 | 1. Cari julat.8.1.2 / TP2
    Semak jawapan
    31 − 12 = 19
  3. Skor memanah P: 8, 9, 8, 9, 8; Q: 10, 6, 10, 7, 9. Bandingkan min dan julat. Pemain manakah lebih konsisten?8.1.2 / TP3
    Semak jawapan
    Min kedua-dua 8.4; julat P 1, Q 4; P lebih konsisten
  4. Data: 3, 5, 7, 8, 10, 12, 15. Cari julat dan julat antara kuartil.8.2.1 / TP2
    Semak jawapan
    Julat 12; Q₁ = 5, Q₃ = 12, JAK = 7
  5. Hitung varians dan sisihan piawai bagi 2, 4, 6, 8.8.2.1 / TP3
    Semak jawapan
    Varians 5; σ ≈ 2.236
  6. Diberi Σx = 60, Σx² = 400, N = 10. Hitung varians dan sisihan piawai.8.2.1 / TP4
    Semak jawapan
    Varians 4; σ = 2
  7. Bina plot kotak bagi: minimum 20, Q₁ 35, median 50, Q₃ 60, maksimum 90. Nyatakan julat antara kuartil.8.2.3 / TP3
    Semak jawapan
    JAK = 25
  8. Setiap data dalam satu set ditambah 5. Apakah kesan terhadap min dan sisihan piawai?8.2.4 / TP4
    Semak jawapan
    Min bertambah 5; sisihan piawai tidak berubah
  9. (KBAT) Data 4, 5, 5, 6, 30. Sukatan serakan manakah paling sesuai? Terangkan.8.2.2 / TP5
    Semak jawapan
    Julat antara kuartil, kerana 30 ialah pencilan
  10. (KBAT) Min lima nombor ialah 8 dan variansnya 4. Nombor 8 ditambah ke dalam set itu. Cari varians baharu.8.2.6 / TP6
    Semak jawapan
    Σx = 48, Σx² = 404, N = 6 → 404/6 − 64 = 10/3 ≈ 3.33
