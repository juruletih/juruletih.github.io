1.TP3[6 markah]
(a) Tentukan nilai kebenaran bagi "9 + 9 = 18". (b) Tulis penafian pernyataan itu dan nyatakan nilai kebenarannya. (c) Gabungkan pernyataan asal dan penafiannya dengan "atau" dan nyatakan nilai kebenaran.
Penyelesaian dan skema markah
  1. (a) benar [1m]
  2. (b) 9 + 9 ≠ 18; palsu [2m]
  3. (c) benar atau palsu = benar [3m]

Penyelesaian dan skema markah

  3. (c) benar atau palsu = benar [3m]

5.TP5 (KBAT)[8 markah]
Implikasi: "Jika x > 5, maka x > 3". (a) Tulis akas, songsangan dan kontrapositif. (b) Nyatakan nilai kebenaran setiap satu apabila implikasi asal benar.
Penyelesaian dan skema markah
  1. (a) Akas: Jika x > 3, maka x > 5 [1m]
  2. Songsangan: Jika bukan x > 5, maka bukan x > 3 [1m]
  3. Kontrapositif: Jika bukan x > 3, maka bukan x > 5 [1m]
  4. (b) Kontrapositif sentiasa benar apabila asal benar [2m]; akas dan songsangan belum tentu [3m]
6.TP5 (KBAT)[8 markah]
Implikasi: "Jika n ialah gandaan 4, maka n ialah nombor genap". (a) Tulis akas, songsangan dan kontrapositif. (b) Nyatakan nilai kebenaran setiap satu apabila implikasi asal benar.
Penyelesaian dan skema markah
  1. (a) Akas: Jika n ialah nombor genap, maka n ialah gandaan 4 [1m]
  2. Songsangan: Jika bukan n ialah gandaan 4, maka bukan n ialah nombor genap [1m]
  3. Kontrapositif: Jika bukan n ialah nombor genap, maka bukan n ialah gandaan 4 [1m]
  4. (b) Kontrapositif sentiasa benar apabila asal benar [2m]; akas dan songsangan belum tentu [3m]
