1.1 Fungsi Kuadratik (1/3)

Ungkapan kuadratik dalam satu pemboleh ubah: ax² + bx + c, dengan a ≠ 0 dan kuasa tertinggi pemboleh ubah ialah 2 (kuasa mesti nombor bulat). b dan c boleh sifar, cth. 3x², x² − 4, 2x² + 5x.

Fungsi kuadratik f(x) = ax² + bx + c ialah hubungan banyak kepada satu (dua nilai x boleh memberi nilai f(x) yang sama). Ujian garis mencancang: setiap garis mencancang memotong graf sekali sahaja.

1.1 Fungsi Kuadratik (2/3)

Ciri graf: berbentuk parabola; a > 0 → bentuk ∪ dengan titik minimum; a < 0 → bentuk ∩ dengan titik maksimum; paksi simetri selari paksi-y, iaitu x = −b/(2a).

Kesan a, b, c: |a| bertambah → graf lebih sempit; tanda a menentukan arah bukaan; c ialah pintasan-y; perubahan b menganjakkan paksi simetri.

1.1 Fungsi Kuadratik (3/3)

Contoh 1. f(x) = x² − 6x + 5: a = 1, b = −6, c = 5. Paksi simetri x = 3. f(3) = −4, jadi titik minimum (3, −4). Pintasan-y = 5.

1.2 Persamaan Kuadratik (1/2)

Bentuk am persamaan kuadratik: ax² + bx + c = 0.

Punca ialah nilai x yang memuaskan persamaan. Pada graf y = ax² + bx + c, punca ialah pintasan-x (titik graf memotong paksi-x).

Kaedah pemfaktoran: susun kepada bentuk am → faktorkan → setiap faktor = 0.

Contoh 2. 2x² + x − 6 = 0 → (2x − 3)(x + 2) = 0 → x = 3/2 atau x = −2.

1.2 Persamaan Kuadratik (2/2)

Awas miskonsepsi: x² = 9x → jangan bahagi dengan x (punca x = 0 hilang). Tulis x² − 9x = 0 → x(x − 9) = 0 → x = 0 atau x = 9.

Lakaran graf: tentukan bentuk (a), pintasan-y (c), punca (pintasan-x) dan titik minimum/maksimum. Jika tiada punca nyata (cth. y = x² + 4), titik minimum terletak pada paksi-y.

Nyatakan sama ada setiap ungkapan berikut ialah ungkapan kuadratik dalam satu pemboleh ubah: (a) 4x² − 1 (b) x³ + 2x (c) 2x² + √x

(a) ya (b) bukan (c) bukan

Latihan 2 daripada 101.1.2 / TP2

Bagi f(x) = −2x² + 8x − 3, nyatakan nilai a, b, c dan sama ada graf mempunyai titik maksimum atau minimum.

a = −2, b = 8, c = −3; titik maksimum

Latihan 3 daripada 101.1.3 / TP3

Cari paksi simetri dan titik minimum bagi f(x) = x² − 6x + 5.

x = 3; (3, −4)

Latihan 4 daripada 101.1.4 / TP3

Segi empat tepat mempunyai panjang (x + 3) cm dan lebar x cm. Luasnya 40 cm². Bentukkan persamaan kuadratik dalam bentuk am.

x² + 3x − 40 = 0

Latihan 5 daripada 101.1.6 / TP2

Selesaikan x² − 5x + 6 = 0.

x = 2 atau x = 3

Latihan 6 daripada 101.1.6 / TP3

Selesaikan 2x² + x − 6 = 0.

x = 3/2 atau x = −2

Latihan 7 daripada 101.1.7 / TP4

Lakarkan graf y = (x − 1)(x − 5). Tandakan pintasan-x, pintasan-y dan titik minimum.

Pintasan-x 1 dan 5; pintasan-y 5; titik minimum (3, −4)

Latihan 8 daripada 101.1.8 / TP4

Hasil darab dua nombor ganjil berturutan ialah 143. Cari kedua-dua nombor itu (positif).

x(x + 2) = 143 → x = 11; 11 dan 13

Latihan 9 daripada 101.1.8 / TP5

(KBAT) Tinggi bola, h = 20t − 5t² meter, t dalam saat. Bilakah bola kembali ke tanah? Berapakah tinggi maksimum?

t = 4 s; maksimum pada t = 2, h = 20 m

Latihan 10 daripada 101.1.8 / TP6

(KBAT) Pagar 20 m digunakan untuk tiga sisi kawasan segi empat tepat di tepi dinding. Jika lebar x m (dua sisi), tunjukkan luas A = x(20 − 2x) dan cari luas maksimum.

Maksimum pada x = 5: A = 50 m²
