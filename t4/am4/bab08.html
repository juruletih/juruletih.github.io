Nota

8.1 Vektor

Vektor mempunyai magnitud dan arah (cth. sesaran, halaju, daya). Skalar mempunyai magnitud sahaja (cth. jisim, laju, masa).

Tatatanda: AB (anak panah di atas) atau huruf tebal a; magnitud |a|.

−a: magnitud sama, arah bertentangan. ka: magnitud |k||a|.

Vektor selari: a selari b jika a = kb. Jika a dan b tidak selari dan ha = kb, maka h = k = 0.

A, B, C segaris jika AB = k BC.

8.2 Penambahan dan Penolakan Vektor

Hukum segi tiga: AB + BC = AC. Hukum segi empat selari: OA + OB = OC bagi segi empat selari OACB.

a − b = a + (−b). Dalam ΔOAB dengan OA = a, OB = b: AB = b − a.

Titik tengah M bagi AB: OM = ½(a + b). Jika AP : PB = 1 : 2, OP = a + ⅓(b − a) = ⅔a + ⅓b.

Vektor paduan dua halaju berserenjang: magnitud √(u² + v²).

8.3 Vektor dalam Satah Cartes

Vektor ditulis xi + yj (i, j vektor unit pada paksi-x dan paksi-y). |xi + yj| = √(x² + y²).

Vektor unit dalam arah r: r̂ = r/|r|.

Jika A(x₁, y₁) dan B(x₂, y₂), AB = (x₂ − x₁)i + (y₂ − y₁)j.

Operasi: tambah/tolak komponen sepadan; darab skalar setiap komponen.

Latihan

Cuba dahulu di kertas. Tekan "Semak jawapan" selepas anda cuba.

  1. Kelaskan sebagai vektor atau skalar: sesaran, jisim, halaju, masa.8.1.1 / TP1
    Semak jawapan
    Vektor: sesaran, halaju; skalar: jisim, masa
  2. p dan q tidak selari dan (h − 2)p = (k + 1)q. Cari h dan k.8.1.4 / TP4
    Semak jawapan
    h = 2, k = −1
  3. AB = 2a + b dan BC = 6a + 3b. Tunjukkan A, B, C segaris dan cari AB : BC.8.1.4 / TP5
    Semak jawapan
    BC = 3AB; 1 : 3
  4. Dalam ΔOAB, OA = a, OB = b. P pada AB dengan AP : PB = 1 : 2. Ungkapkan OP.8.2.1 / TP3
    Semak jawapan
    ⅔a + ⅓b
  5. Bot bergerak 4 km/j ke timur dalam arus 3 km/j ke utara. Cari laju paduan dan arahnya dari timur.8.2.2 / TP4
    Semak jawapan
    5 km/j; 36.87°
  6. a = 2i + 3j, b = i − j. Cari 2a − 3b.8.3.3 / TP3
    Semak jawapan
    i + 9j
  7. A(1, 2), B(4, 6). Cari AB dan |AB|.8.3.1 / TP3
    Semak jawapan
    3i + 4j; 5
  8. Cari vektor unit dalam arah 5i − 12j.8.3.2 / TP4
    Semak jawapan
    (5i − 12j)/13
  9. a = 2i + kj selari dengan b = 4i + 6j. Cari k.8.3.3 / TP4
    Semak jawapan
    k = 3
  10. (KBAT) Kedudukan kapal r = (2 + 3t)i + (1 + 4t)j km selepas t jam. Hitung jaraknya dari asalan apabila t = 2.8.3.4 / TP6
    Semak jawapan
    8i + 9j; √145 ≈ 12.04 km
