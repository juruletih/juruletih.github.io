Bab 3: Sistem Persamaan

Nota

3.1 Sistem Persamaan Linear dalam Tiga Pemboleh Ubah

Contoh persamaan linear tiga pemboleh ubah: 2x + y − z = 5. Setiap persamaan mewakili sebuah satah dalam ruang tiga dimensi.

Sistem boleh mempunyai satu penyelesaian, tiada penyelesaian atau penyelesaian tak terhingga.

Kaedah penghapusan: hapuskan satu pemboleh ubah daripada dua pasang persamaan untuk mendapat sistem dua pemboleh ubah, selesaikan, kemudian gantikan semula.

Contoh. x + y + z = 6, 2x − y + z = 3, x + 2y − z = 2. (1) + (3): 2x + 3y = 8; (2) + (3): 3x + y = 5 → x = 1, y = 2, z = 3.

3.2 Persamaan Serentak Linear dan Tak Linear

Ungkapkan satu pemboleh ubah daripada persamaan linear, gantikan ke dalam persamaan tak linear, selesaikan persamaan kuadratik, kemudian cari pemboleh ubah kedua.

Contoh. y = x + 1 dan x² + y² = 25 → x² + x − 12 = 0 → (3, 4) dan (−4, −3).

Bilangan titik persilangan garis dan lengkung bergantung pada pembezalayan persamaan kuadratik yang terhasil.

Latihan

Cuba dahulu di kertas. Tekan "Semak jawapan" selepas anda cuba.

  1. Selesaikan x + y + z = 10, y + z = 7, z = 4.3.1.2 / TP2
    Semak jawapan
    (3, 3, 4)
  2. Selesaikan x + y + z = 6, 2x − y + z = 3, x + 2y − z = 2.3.1.2 / TP3
    Semak jawapan
    x = 1, y = 2, z = 3
  3. Selesaikan 2x + y − z = 1, x − y + z = 5, x + y + z = 9.3.1.2 / TP4
    Semak jawapan
    x = 2, y = 2, z = 5
  4. Sebatang pen, sebuah buku dan sebuah beg berharga RM30; sebatang pen dan dua buah buku RM14; dua batang pen dan sebuah beg RM26. Cari harga setiap barang.3.1.3 / TP5
    Semak jawapan
    Pen RM2, buku RM6, beg RM22
  5. Selesaikan y = x + 1 dan x² + y² = 25.3.2.1 / TP3
    Semak jawapan
    (3, 4), (−4, −3)
  6. Selesaikan x + y = 5 dan xy = 6.3.2.1 / TP3
    Semak jawapan
    (2, 3), (3, 2)
  7. Selesaikan y = 2x − 1 dan x² + xy = 4.3.2.1 / TP4
    Semak jawapan
    (−1, −3), (4/3, 5/3)
  8. Segi empat tepat berperimeter 20 cm dan luas 24 cm². Cari sisinya.3.2.2 / TP4
    Semak jawapan
    6 cm dan 4 cm
  9. (KBAT) Lengkung y = ax² + bx + c melalui (0, 1), (1, 4) dan (−1, 0). Cari a, b dan c.3.1.3 / TP6
    Semak jawapan
    a = 1, b = 2, c = 1
  10. (KBAT) Segi tiga bersudut tegak mempunyai hipotenus 13 cm dan perimeter 30 cm. Cari luasnya.3.2.2 / TP6
    Semak jawapan
    x + y = 17, x² + y² = 169 → 5 dan 12; luas 30 cm²
