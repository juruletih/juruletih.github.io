2Contoh berpandu

Baca setiap langkah bersama sebabnya. Tutup skrin dan cuba tulis semula sendiri.

Contoh A: persamaan indeks

Selesaikan 2ˣ⁺¹ = 32.

  1. 32 = 2⁵Tulis kedua-dua belah dengan asas sama.
  2. 2ˣ⁺¹ = 2⁵Asas sama.
  3. x + 1 = 5Samakan indeks.
  4. x = 4Selesaikan.

Semak: 2⁵ = 32 ✓

Contoh B: persamaan logaritma

Selesaikan log₂ x + log₂ (x + 2) = 3.

  1. log₂ x(x + 2) = 3log a + log b = log ab.
  2. x(x + 2) = 2³ = 8Tukar ke bentuk indeks.
  3. x² + 2x − 8 = 0 → (x + 4)(x − 2) = 0Selesaikan kuadratik.
  4. x = 2 atau x = −4Dua calon.
  5. x = 2 sahajalog₂ (−4) tidak tertakrif, jadi x = −4 ditolak.

Semak: log₂ 2 + log₂ 4 = 1 + 2 = 3 ✓

3Contoh separa siap

Langkah bergaris putus-putus kosong. Tulis langkah itu di kertas dahulu, kemudian tekan "Lihat langkah". Bilangan langkah kosong bertambah.

1. Selesaikan 9ˣ = 27. 1 langkah kosong

  1. 3²ˣ = 3³Asas sama: 9 = 3², 27 = 3³.
  2. 2x = 3Samakan indeks.
  3. Lihat langkahx = 3/2Bahagi.

2. Permudahkan √50 + √8. 2 langkah kosong

  1. √50 = √(25 × 2) = 5√2Cari faktor kuasa dua sempurna.
  2. Lihat langkah√8 = √(4 × 2) = 2√2Sama.
  3. Lihat langkah5√2 + 2√2 = 7√2Surd serupa boleh ditambah.

3. Cari nilai log₅ 125. 2 langkah kosong

  1. 125 = 5³Tulis sebagai kuasa asas.
  2. Lihat langkahlog₅ 5³ = 3 log₅ 5log aⁿ = n log a.
  3. Lihat langkah= 3log₅ 5 = 1.

4. Rasionalkan penyebut 6/(3 − √3). 3 langkah kosong

  1. Darab dengan (3 + √3)/(3 + √3)Konjugat penyebut.
  2. Lihat langkahPengangka: 6(3 + √3)Darab.
  3. Lihat langkahPenyebut: 3² − (√3)² = 9 − 3 = 6(a − b)(a + b) = a² − b².
  4. Lihat langkah= 3 + √3Permudahkan.

1.

Penyelesaian
  1. b² − 4ac = 0: k² − 4(1)(1) = 0
  2. k² = 4; k = 2
2.
Diberi x − y = 3 dan x² + y² = 29. Nilai xy ialah
Penyelesaian
  1. (x − y)² = x² + y² − 2xy
  2. 9 = 29 − 2xy
  3. xy = 10
3.
