2Contoh berpandu

Baca setiap langkah bersama sebabnya. Tutup skrin dan cuba tulis semula sendiri.

Contoh A: fungsi gubahan

f(x) = 2x + 1 dan g(x) = x². Cari gf(3).

  1. gf(3) = g(f(3))Dalam gf, f dilakukan dahulu (paling dekat dengan x).
  2. f(3) = 2(3) + 1 = 7Kira fungsi dalam dahulu.
  3. g(7) = 7² = 49Masukkan hasil ke dalam g.

Semak: gf(x) = (2x + 1)², gf(3) = 7² = 49 ✓

Contoh B: fungsi songsang

f(x) = 3x − 5. Cari f⁻¹(x) dan f⁻¹(7).

  1. Biar y = 3x − 5Tulis fungsi sebagai persamaan.
  2. y + 5 = 3xAsingkan sebutan x.
  3. x = (y + 5)/3Jadikan x perkara rumus.
  4. f⁻¹(x) = (x + 5)/3Tukar y kepada x.
  5. f⁻¹(7) = 12/3 = 4Gantikan.

Semak: f(4) = 12 − 5 = 7 ✓

3Contoh separa siap

Langkah bergaris putus-putus kosong. Tulis langkah itu di kertas dahulu, kemudian tekan "Lihat langkah". Bilangan langkah kosong bertambah.

1. f(x) = 4x − 3. Cari f(2). 1 langkah kosong

  1. f(2) = 4(2) − 3Gantikan x = 2.
  2. = 8 − 3Darab dahulu.
  3. Lihat langkah= 5Tolak.

2. f(x) = x + 2 dan g(x) = 3x. Cari fg(x). 2 langkah kosong

  1. fg(x) = f(g(x))g dilakukan dahulu.
  2. Lihat langkah= f(3x)Gantikan g(x).
  3. Lihat langkah= 3x + 2Gantikan x dalam f dengan 3x.

3. f(x) = 2x + 7. Cari f⁻¹(x). 2 langkah kosong

  1. Biar y = 2x + 7Persamaan.
  2. Lihat langkahx = (y − 7)/2Jadikan x perkara rumus.
  3. Lihat langkahf⁻¹(x) = (x − 7)/2Tukar y kepada x.

4. f(x) = 2x − 1 dan g(x) = x² + 1. Cari nilai x jika gf(x) = 10. 3 langkah kosong

  1. gf(x) = (2x − 1)² + 1Gubahan.
  2. Lihat langkah(2x − 1)² + 1 = 10Samakan.
  3. Lihat langkah(2x − 1)² = 9, 2x − 1 = ±3Punca kuasa dua kedua-dua belah.
  4. Lihat langkahx = 2 atau x = −1Selesaikan kedua-dua kes.

5Cari silap

Kesilapan ini paling kerap berlaku dalam bab ini. Mengenal pasti silap orang lain membantu anda mengelakkannya.

1.
f(x) = 2x + 1 dan g(x) = x². Cari gf(3). Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Dalam gf(x), f bertindak dahulu ke atas x. Baca dari kanan ke kiri.

  1. gf(3) = g(f(3))
  2. f(3) = 7, g(7) = 49
2.
f(x) = 3x − 5. Cari f⁻¹(7). Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

f⁻¹ ialah fungsi songsang (membatalkan f), bukan salingan 1/f.

  1. f⁻¹(x) = (x + 5)/3
  2. f⁻¹(7) = 4
3.
f(x) = x². Cari f(x + 1). Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Seluruh x + 1 menggantikan x, jadi seluruhnya dikuasaduakan.

  1. f(x + 1) = (x + 1)² = x² + 2x + 1
4.
f(x) = 2x + 7. Cari f⁻¹(x). Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Untuk memindahkan +7 ke sebelah lain, tolak 7. Semak: f(0) = 7, f⁻¹(7) mesti 0.

  1. x = (y − 7)/2
5.
Adakah f(x) = x² (x nombor nyata) mempunyai fungsi songsang? Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Fungsi songsang hanya wujud bagi fungsi satu-ke-satu.

  1. f(2) = f(−2) = 4: bukan satu-ke-satu
  2. Tiada songsang bagi domain semua nombor nyata

1.

Penyelesaian

  2. 2 ≠ 3
2.
Nilai minimum bagi y = 2x² + 16x + 35 ialah
Penyelesaian
  1. Bentuk verteks: y = 2(x − −4)² + 3
  2. Minimum = 3
3.
Hasil darab punca bagi persamaan x² + 5x = 0 ialah
Penyelesaian
  1. Hasil darab = c/a = 0
