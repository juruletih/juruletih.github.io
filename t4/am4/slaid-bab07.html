7.1 Pembahagi Tembereng Garis

Titik tengah AB: ((x₁ + x₂)/2, (y₁ + y₂)/2).

Titik P membahagi AB dengan nisbah AP : PB = m : n: P = ((nx₁ + mx₂)/(m + n), (ny₁ + my₂)/(m + n)).

Contoh. A(1, 2), B(7, 8), AP : PB = 1 : 2 → P(3, 4).

7.2 Garis Lurus Selari dan Serenjang

Selari: m₁ = m₂. Serenjang: m₁ × m₂ = −1.

Persamaan garis melalui (x₁, y₁) dengan kecerunan m: y − y₁ = m(x − x₁).

Pembahagi dua sama serenjang AB: melalui titik tengah AB dan berserenjang dengan AB.

7.3 Luas Poligon

Luas = ½ |(x₁y₂ + x₂y₃ + … + xₙy₁) − (y₁x₂ + y₂x₃ + … + yₙx₁)|, bucu disusun mengikut tertib (lawan arah jam memberi nilai positif sebelum nilai mutlak).

Luas segi tiga = 0 bermaksud tiga titik itu segaris.

7.4 Persamaan Lokus

Lokus ialah set semua titik yang memenuhi syarat tertentu. Biarkan P(x, y) dan tulis syarat sebagai persamaan.

Jarak tetap r dari (a, b): (x − a)² + (y − b)² = r² (bulatan).

Sama jarak dari A dan B: PA = PB (pembahagi dua sama serenjang AB).

Nisbah PA : PB = m : n: n²PA² = m²PB².
