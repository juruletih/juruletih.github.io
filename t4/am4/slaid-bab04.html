4.1 Hukum Indeks

aᵐ × aⁿ = aᵐ⁺ⁿ; aᵐ ÷ aⁿ = aᵐ⁻ⁿ; (aᵐ)ⁿ = aᵐⁿ; a⁰ = 1; a⁻ⁿ = 1/aⁿ; a^(m/n) = (ⁿ√a)ᵐ.

Persamaan indeks: samakan asas, kemudian samakan indeks. 9ˣ = 27 → 3²ˣ = 3³ → x = 3/2.

Faktorkan sebutan sepunya: 2ⁿ⁺² − 2ⁿ = 2ⁿ(4 − 1) = 3(2ⁿ).

4.2 Hukum Surd

Surd ialah punca kuasa yang tidak dapat dipermudah menjadi nombor nisbah, cth. √5. Surd ialah nombor tak nisbah (perpuluhan tak berulang dan tak tamat).

√a × √b = √(ab); √a ÷ √b = √(a/b); √12 = 2√3.

Menisbahkan penyebut: 6/√3 = 6√3/3 = 2√3; 1/(√5 − 2) = (√5 + 2)/(5 − 4) = √5 + 2 (darab dengan konjugat).

4.3 Hukum Logaritma

aˣ = N ⇔ logₐ N = x (a > 0, a ≠ 1). logₐ 1 = 0, logₐ a = 1. log ialah asas 10; ln ialah asas e.

logₐ xy = logₐ x + logₐ y; logₐ (x/y) = logₐ x − logₐ y; logₐ xⁿ = n logₐ x.

Penukaran asas: logₐ b = log_c b / log_c a; logₐ b = 1/log_b a.

Bagi persamaan logaritma, semak penyelesaian supaya hujah logaritma positif.

4.4 Aplikasi

Faedah kompaun A = P(1 + r)ⁿ; pertumbuhan/susutan eksponen N = N₀aᵗ; pH = −log[H⁺]; aras bunyi = 10 log(I/I₀).

Untuk mencari eksponen yang tidak diketahui, ambil logaritma kedua-dua belah.
