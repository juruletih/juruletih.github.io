Bab 2: Fungsi Kuadratik

Matematik Tambahan Tingkatan 4 · Nota, latihan dan kuiz

Selepas bab ini, anda boleh

  • menyelesaikan persamaan kuadratik (penyempurnaan kuasa dua dan rumus), membentuk persamaan daripada punca dan menyelesaikan ketaksamaan kuadratik (SP 2.1.1–2.1.3)
  • menghubungkaitkan jenis punca dengan pembezalayan b² − 4ac dan menyelesaikan masalah (SP 2.2.1, 2.2.2)
  • menganalisis kesan perubahan a, b, c, h dan k, bentuk verteks, melakar graf dan menyelesaikan masalah fungsi kuadratik (SP 2.3.1–2.3.6)

Slaid

Buka slaid

Slaid penuh skrin. Guna anak panah atau leret jari. Boleh dicetak.

Nota

2.1 Persamaan dan Ketaksamaan Kuadratik

Bentuk am: ax² + bx + c = 0, a ≠ 0. Rumus: x = [−b ± √(b² − 4ac)] / 2a.

Penyempurnaan kuasa dua: x² + 6x + 5 = (x + 3)² − 4.

Jika α dan β punca: α + β = −b/a, αβ = c/a; persamaan: x² − (α + β)x + αβ = 0.

Ketaksamaan: cari punca, lakar graf. (x + 2)(x − 3) < 0 → −2 < x < 3; x(x − 4) ≥ 0 → x ≤ 0 atau x ≥ 4.

2.2 Jenis-jenis Punca

Pembezalayan D = b² − 4ac. D > 0: dua punca nyata berbeza; D = 0: dua punca sama; D < 0: tiada punca nyata.

"Punca nyata" bermaksud D ≥ 0. Garis menyentuh lengkung (tangen) apabila persamaan gabungan mempunyai D = 0.

2.3 Fungsi Kuadratik

a > 0: graf berbentuk ∪ (titik minimum); a < 0: berbentuk ∩ (titik maksimum). c ialah pintasan-y.

Bentuk verteks f(x) = a(x − h)² + k: titik pusingan (h, k), paksi simetri x = h.

Perubahan h: graf ditranslasi mengufuk; perubahan k (atau c): ditranslasi mencancang; |a| besar: graf lebih sempit.

Kedudukan graf: D > 0 memotong paksi-x di dua titik; D = 0 menyentuh; D < 0 tidak bersilang.

Contoh. f(x) = −2x² + 8x − 3 = −2(x − 2)² + 5 → titik maksimum (2, 5).
