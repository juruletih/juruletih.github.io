3.1 Sistem Persamaan Linear dalam Tiga Pemboleh Ubah (1/2)

Contoh persamaan linear tiga pemboleh ubah: 2x + y − z = 5. Setiap persamaan mewakili sebuah satah dalam ruang tiga dimensi.

Sistem boleh mempunyai satu penyelesaian, tiada penyelesaian atau penyelesaian tak terhingga.

Kaedah penghapusan: hapuskan satu pemboleh ubah daripada dua pasang persamaan untuk mendapat sistem dua pemboleh ubah, selesaikan, kemudian gantikan semula.

3.1 Sistem Persamaan Linear dalam Tiga Pemboleh Ubah (2/2)

Contoh. x + y + z = 6, 2x − y + z = 3, x + 2y − z = 2. (1) + (3): 2x + 3y = 8; (2) + (3): 3x + y = 5 → x = 1, y = 2, z = 3.

3.2 Persamaan Serentak Linear dan Tak Linear

Ungkapkan satu pemboleh ubah daripada persamaan linear, gantikan ke dalam persamaan tak linear, selesaikan persamaan kuadratik, kemudian cari pemboleh ubah kedua.

Contoh. y = x + 1 dan x² + y² = 25 → x² + x − 12 = 0 → (3, 4) dan (−4, −3).

Bilangan titik persilangan garis dan lengkung bergantung pada pembezalayan persamaan kuadratik yang terhasil.
