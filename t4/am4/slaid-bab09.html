Bab 9: Penyelesaian Segi Tiga

Matematik Tambahan Tingkatan 4

Disediakan oleh: JURULETIH

Selepas bab ini, anda boleh

  • menggunakan petua sinus termasuk kes berambiguiti untuk menyelesaikan segi tiga (SP 9.1.1–9.1.5)
  • mentahkik dan menggunakan petua kosinus (SP 9.2.1, 9.2.2)
  • menentukan luas segi tiga menggunakan ½ab sin C dan rumus Heron serta menyelesaikan masalah (SP 9.3.1–9.3.3, 9.4.1)

9.1 Petua Sinus (1/2)

a/sin A = b/sin B = c/sin C. Digunakan apabila diberi dua sudut dan satu sisi, atau dua sisi dan satu sudut bukan kandung.

Kes berambiguiti (diberi a, b dan sudut tirus A): jika b sin A < a < b, terdapat dua segi tiga (B tirus atau B cakah = 180° − B tirus). Jika a < b sin A, tiada segi tiga; jika a = b sin A, satu segi tiga bersudut tegak; jika a ≥ b, satu segi tiga.

9.1 Petua Sinus (2/2)

Contoh. a = 10, b = 12, A = 50°: sin B = 0.9193 → B = 66.82° atau 113.18°.

9.2 Petua Kosinus

a² = b² + c² − 2bc cos A; cos A = (b² + c² − a²)/2bc.

Digunakan apabila diberi dua sisi dan sudut kandung, atau tiga sisi.

Jika cos A < 0, A ialah sudut cakah. Sudut terbesar bertentangan dengan sisi terpanjang.

9.3 Luas Segi Tiga dan Aplikasi

Luas = ½ab sin C (dua sisi dan sudut kandung).

Rumus Heron: luas = √[s(s − a)(s − b)(s − c)], s = (a + b + c)/2.

Masalah tiga dimensi/sebenar: lakar, kenal pasti segi tiga yang sesuai, kemudian pilih petua sinus, petua kosinus atau rumus luas.
