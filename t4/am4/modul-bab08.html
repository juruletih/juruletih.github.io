2Contoh berpandu

Baca setiap langkah bersama sebabnya. Tutup skrin dan cuba tulis semula sendiri.

Contoh A: magnitud dan vektor unit

a = 3i + 4j. Cari |a| dan vektor unit dalam arah a.

  1. |a| = √(3² + 4²)Magnitud: Pythagoras.
  2. = √25 = 5Kira.
  3. Vektor unit = a/|a|Bahagi vektor dengan magnitudnya.
  4. = (3i + 4j)/5 = (3/5)i + (4/5)jPermudahkan.

Semak: (3/5)² + (4/5)² = 1 ✓

Contoh B: vektor di antara dua titik

OA = 2i + j dan OB = 5i + 5j. Cari AB dan |AB|.

  1. AB = AO + OB = −OA + OBHukum segi tiga.
  2. AB = OB − OAAkhir tolak awal.
  3. = (5 − 2)i + (5 − 1)j = 3i + 4jTolak komponen.
  4. |AB| = √(9 + 16) = 5Magnitud.

3Contoh separa siap

Langkah bergaris putus-putus kosong. Tulis langkah itu di kertas dahulu, kemudian tekan "Lihat langkah". Bilangan langkah kosong bertambah.

1. a = i + 2j dan b = 3i − j. Cari 2a + b. 1 langkah kosong

  1. 2a = 2i + 4jDarab skalar.
  2. 2a + b = (2 + 3)i + (4 − 1)jTambah komponen.
  3. Lihat langkah= 5i + 3jKira.

2. Cari |6i − 8j|. 2 langkah kosong

  1. |v| = √(6² + (−8)²)Rumus magnitud.
  2. Lihat langkah= √100Kira.
  3. Lihat langkah= 10Punca kuasa dua.

3. a = 2i + 3j dan b = ki + 6j adalah selari. Cari k. 2 langkah kosong

  1. b = λaVektor selari ialah gandaan skalar.
  2. Lihat langkah6 = 3λ, λ = 2Bandingkan komponen j.
  3. Lihat langkahk = 2 × 2 = 4Bandingkan komponen i.

4. Cari vektor unit dalam arah 5i − 12j. 3 langkah kosong

  1. |v| = √(25 + 144) = 13Magnitud.
  2. Lihat langkahVektor unit = v/|v|Rumus.
  3. Lihat langkah= (5i − 12j)/13Gantikan.
  4. Lihat langkah= (5/13)i − (12/13)jPermudahkan.

5Cari silap

Kesilapan ini paling kerap berlaku dalam bab ini. Mengenal pasti silap orang lain membantu anda mengelakkannya.

1.
OA = 2i + j, OB = 5i + 5j. Cari AB. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Vektor dari A ke B = kedudukan akhir (B) tolak kedudukan awal (A).

  1. AB = OB − OA
  2. = 3i + 4j
2.
Cari |3i + 4j|. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Komponen i dan j berserenjang, jadi gunakan teorem Pythagoras.

  1. |3i + 4j| = √(3² + 4²)
  2. = 5
3.
Cari |6i − 8j|. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Komponen dikuasaduakan dahulu; (−8)² = 64 positif. Magnitud sentiasa wujud.

  1. |v| = √(6² + (−8)²) = √100
  2. = 10
4.
Cari vektor unit dalam arah 5i − 12j. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Vektor unit mempunyai magnitud 1, jadi BAHAGI dengan magnitud.

  1. Vektor unit = (5i − 12j)/13
5.
a = 2i + 3j dan b = ki + 6j selari. Cari k. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Selari bermaksud satu vektor gandaan skalar yang lain, bukan sama.

  1. Selari: b = λa, λ = 6/3 = 2
  2. k = 2 × 2 = 4
