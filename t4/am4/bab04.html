Bab 4: Indeks, Surd dan Logaritma

Matematik Tambahan Tingkatan 4 · Nota, latihan dan kuiz

Selepas bab ini, anda boleh

  • mempermudah ungkapan dan menyelesaikan masalah menggunakan hukum indeks (SP 4.1.1, 4.1.2)
  • membanding nombor nisbah dan tak nisbah, mempermudah surd dan menisbahkan penyebut (SP 4.2.1–4.2.5)
  • menghubungkaitkan indeks dengan logaritma, menggunakan hukum logaritma dan penukaran asas (SP 4.3.1–4.3.5)
  • menyelesaikan masalah yang melibatkan indeks, surd dan logaritma (SP 4.4.1)

Nota

4.1 Hukum Indeks

aᵐ × aⁿ = aᵐ⁺ⁿ; aᵐ ÷ aⁿ = aᵐ⁻ⁿ; (aᵐ)ⁿ = aᵐⁿ; a⁰ = 1; a⁻ⁿ = 1/aⁿ; a^(m/n) = (ⁿ√a)ᵐ.

Persamaan indeks: samakan asas, kemudian samakan indeks. 9ˣ = 27 → 3²ˣ = 3³ → x = 3/2.

Faktorkan sebutan sepunya: 2ⁿ⁺² − 2ⁿ = 2ⁿ(4 − 1) = 3(2ⁿ).

4.2 Hukum Surd

Surd ialah punca kuasa yang tidak dapat dipermudah menjadi nombor nisbah, cth. √5. Surd ialah nombor tak nisbah (perpuluhan tak berulang dan tak tamat).

√a × √b = √(ab); √a ÷ √b = √(a/b); √12 = 2√3.

Menisbahkan penyebut: 6/√3 = 6√3/3 = 2√3; 1/(√5 − 2) = (√5 + 2)/(5 − 4) = √5 + 2 (darab dengan konjugat).

4.3 Hukum Logaritma

aˣ = N ⇔ logₐ N = x (a > 0, a ≠ 1). logₐ 1 = 0, logₐ a = 1. log ialah asas 10; ln ialah asas e.

logₐ xy = logₐ x + logₐ y; logₐ (x/y) = logₐ x − logₐ y; logₐ xⁿ = n logₐ x.

Penukaran asas: logₐ b = log_c b / log_c a; logₐ b = 1/log_b a.

Bagi persamaan logaritma, semak penyelesaian supaya hujah logaritma positif.

4.4 Aplikasi

Faedah kompaun A = P(1 + r)ⁿ; pertumbuhan/susutan eksponen N = N₀aᵗ; pH = −log[H⁺]; aras bunyi = 10 log(I/I₀).

Untuk mencari eksponen yang tidak diketahui, ambil logaritma kedua-dua belah.

Latihan

Cuba dahulu di kertas. Tekan "Semak jawapan" selepas anda cuba.

  1. Selesaikan 4ˣ × 2ˣ⁻¹ = 16.4.1.2 / TP4
    Semak jawapan
    x = 5/3
  2. Tunjukkan bahawa 3ⁿ⁺² − 3ⁿ boleh dibahagi tepat dengan 8.4.1.1 / TP5
    Semak jawapan
    3ⁿ(9 − 1) = 8(3ⁿ)
  3. Permudahkan 3√2 + √8 dan √3 × √6.4.2.3 / TP3
    Semak jawapan
    5√2; 3√2
  4. Nisbahkan penyebut 1/(√5 − 2).4.2.4 / TP4
    Semak jawapan
    √5 + 2
  5. Selesaikan √(x + 7) = x + 1.4.2.5 / TP5
    Semak jawapan
    x = 2 (x = −3 ditolak)
  6. Diberi log 2 = 0.301 dan log 3 = 0.477, cari log 12.4.3.3 / TP3
    Semak jawapan
    1.079
  7. Selesaikan log₂ x + log₂ (x − 2) = 3.4.3.5 / TP4
    Semak jawapan
    x = 4
  8. Selesaikan log₂ x = log₄ (3x + 4).4.3.5 / TP6
    Semak jawapan
    x = 4
  9. RM1 000 dilabur pada kadar 6% setahun dikompaun tahunan. Selepas berapa tahun pelaburan menjadi dua kali ganda?4.4.1 / TP4
    Semak jawapan
    1.06ⁿ = 2 → n = 11.9 → 12 tahun
  10. (KBAT) Bakteria A: N = 100(2ᵗ); bakteria B: N = 800(2^(t/2)), t dalam jam. Bilakah bilangan kedua-duanya sama?4.4.1 / TP6
    Semak jawapan
    t = 6 jam
