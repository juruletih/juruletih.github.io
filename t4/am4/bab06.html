Bab 6: Hukum Linear

Matematik Tambahan Tingkatan 4 · Nota, latihan dan kuiz

Selepas bab ini, anda boleh

Slaid

Buka slaid

Nota

6.1 Hubungan Linear dan Tak Linear

Hubungan linear: graf garis lurus Y = mX + c. Hubungan tak linear: graf lengkung.

Garis lurus penyuaian terbaik: melalui sebanyak mungkin titik, dengan titik-titik lain bertaburan seimbang di kedua-dua belah garis.

Daripada garis: kecerunan m dan pintasan-Y c; nilai yang tidak diketahui boleh dianggar daripada graf atau persamaan.

6.2 Hukum Linear dan Hubungan Tak Linear

Tukarkan persamaan tak linear kepada bentuk Y = mX + c:

y = ax² + b → Y = y, X = x², m = a, c = b.

y = a/x + b → Y = y, X = 1/x.

y = px + q/x → xy = px² + q: Y = xy, X = x².

y = abˣ → log y = (log b)x + log a: Y = log y, X = x.

y = kxⁿ → log y = n log x + log k: Y = log y, X = log x.

6.3 Aplikasi Hukum Linear

Langkah: (1) tentukan Y dan X; (2) bina jadual nilai baharu; (3) plot dan lukis garis penyuaian terbaik; (4) cari m dan c; (5) tentukan pemalar asal; (6) jawab soalan.

Cth. T = k√L (bandul): plot T² melawan L, kecerunan = k².

Latihan

Cuba dahulu di kertas. Tekan "Semak jawapan" selepas anda cuba.

  1. Garis penyuaian terbaik melalui (1, 3) dan (5, 11). Bentuk persamaannya dan anggarkan y apabila x = 3.5.6.1.3 / TP3
    Semak jawapan
    y = 2x + 1; 8
  2. Tukarkan y = ax² + b kepada bentuk linear dan nyatakan X, Y, m, c.6.2.1 / TP3
    Semak jawapan
    Y = y, X = x², m = a, c = b
  3. Tukarkan y = abˣ kepada bentuk linear.6.2.1 / TP3
    Semak jawapan
    log y = (log b)x + log a
  4. Tukarkan y = px + q/x kepada bentuk linear.6.2.1 / TP4
    Semak jawapan
    xy = px² + q
  5. Graf y melawan x² melalui (1, 5) dan (4, 11). Cari hubungan antara y dan x.6.2.1 / TP5
    Semak jawapan
    y = 2x² + 3
  6. Graf log y melawan x mempunyai kecerunan 0.3 dan pintasan 0.6. Diberi y = abˣ, cari a dan b.6.3.1 / TP5
    Semak jawapan
    a = 3.98, b = 2.00
  7. Jadual: x = 1, 2, 3, 4; y = 2, 8, 18, 32. Tentukan hubungan antara x dan y.6.1.1 / TP4
    Semak jawapan
    y = 2x²
  8. Graf y melawan 1/x melalui (0.5, 4) dan (0.25, 3). Diberi y = p/x + q, cari p dan q.6.3.1 / TP5
    Semak jawapan
    p = 4, q = 2
  9. Bagi bandul T = k√L, graf T² melawan L mempunyai kecerunan 4. Cari k.6.3.1 / TP4
    Semak jawapan
    k = 2
  10. (KBAT) Suhu air θ = 80(0.9)ᵗ °C, t dalam minit. Tukar kepada bentuk linear dan tentukan bila suhu mula kurang daripada 40 °C.6.3.1 / TP6
    Semak jawapan
    log θ = t log 0.9 + log 80; t = 7 minit
