5.1 Janjang Aritmetik

Janjang aritmetik (JA): beza sepunya d = Tₙ₊₁ − Tₙ adalah tetap.

Tₙ = a + (n − 1)d; Sₙ = n/2 [2a + (n − 1)d] = n/2 (a + l), l = sebutan terakhir.

Tₙ = Sₙ − Sₙ₋₁.

Contoh. 3, 7, 11, …: T₁₀ = 3 + 9(4) = 39; S₁₀ = 5(6 + 36) = 210.

5.2 Janjang Geometri

Janjang geometri (JG): nisbah sepunya r = Tₙ₊₁ / Tₙ adalah tetap.

Tₙ = arⁿ⁻¹; Sₙ = a(rⁿ − 1)/(r − 1) (r > 1) atau a(1 − rⁿ)/(1 − r) (r < 1).

Hasil tambah hingga ketakterhinggaan S∞ = a/(1 − r), hanya jika |r| < 1.

Perpuluhan berulang: 0.444… = 0.4 + 0.04 + … = 0.4/(1 − 0.1) = 4/9.
