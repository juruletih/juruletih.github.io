2Contoh berpandu

Baca setiap langkah bersama sebabnya. Tutup skrin dan cuba tulis semula sendiri.

Contoh A: janjang aritmetik

Bagi janjang 5, 8, 11, …, cari T₂₀ dan S₂₀.

  1. a = 5, d = 8 − 5 = 3Beza sepunya tetap: janjang aritmetik.
  2. T₂₀ = a + (n − 1)d = 5 + 19(3)Sebutan ke-20 ada 19 langkah d dari sebutan pertama.
  3. T₂₀ = 62Kira.
  4. S₂₀ = n/2 (a + l) = 20/2 (5 + 62)Hasil tambah dengan sebutan pertama dan terakhir.
  5. S₂₀ = 670Kira.

Contoh B: hasil tambah ketakterhinggaan

Cari hasil tambah ketakterhinggaan bagi 81, 27, 9, …

  1. r = 27 ÷ 81 = 1/3Nisbah = sebutan ÷ sebutan sebelumnya.
  2. |r| < 1, jadi S∞ wujudSemak syarat dahulu.
  3. S∞ = a/(1 − r) = 81/(1 − 1/3)Rumus.
  4. = 81 ÷ 2/3 = 121.5Kira.

Semak: 81 + 27 + 9 + 3 + 1 = 121, menghampiri 121.5 ✓

3Contoh separa siap

Langkah bergaris putus-putus kosong. Tulis langkah itu di kertas dahulu, kemudian tekan "Lihat langkah". Bilangan langkah kosong bertambah.

1. Cari sebutan ke-10 bagi 2, 7, 12, … 1 langkah kosong

  1. a = 2, d = 5Kenal pasti.
  2. T₁₀ = 2 + 9(5)Tₙ = a + (n − 1)d.
  3. Lihat langkah= 47Kira.

2. Cari sebutan ke-6 bagi 3, 6, 12, … 2 langkah kosong

  1. a = 3, r = 2Kenal pasti.
  2. Lihat langkahT₆ = 3 × 2⁵Tₙ = arⁿ⁻¹.
  3. Lihat langkah= 96Kira.

3. Janjang aritmetik dengan a = 4 dan d = 3. Cari S₁₀. 2 langkah kosong

  1. S₁₀ = 10/2 [2(4) + 9(3)]Sₙ = n/2 [2a + (n − 1)d].
  2. Lihat langkah= 5(8 + 27)Permudahkan.
  3. Lihat langkah= 175Kira.

4. Janjang geometri dengan a = 2 dan r = 3. Cari S₅. 3 langkah kosong

  1. Sₙ = a(rⁿ − 1)/(r − 1)Rumus apabila r > 1.
  2. Lihat langkahS₅ = 2(3⁵ − 1)/2Gantikan.
  3. Lihat langkah= 243 − 1Permudahkan.
  4. Lihat langkah= 242Kira.

5Cari silap

Kesilapan ini paling kerap berlaku dalam bab ini. Mengenal pasti silap orang lain membantu anda mengelakkannya.

1.
Cari T₂₀ bagi 5, 8, 11, … Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Tₙ = a + (n − 1)d. Semak dengan T₂ = 5 + 1(3) = 8 ✓.

  1. T₂₀ = 5 + 19(3)
  2. = 62
2.
Cari S∞ bagi 81, 27, 9, … Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

r = sebutan kemudian ÷ sebutan sebelumnya. Hasil tambah nombor positif tidak boleh negatif.

  1. r = 27 ÷ 81 = 1/3
  2. S∞ = 81/(1 − 1/3) = 121.5
3.
Cari S∞ bagi 2, 4, 8, … Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

S∞ hanya wujud apabila −1 < r < 1.

  1. |r| > 1: hasil tambah ketakterhinggaan tidak wujud
4.
Cari T₆ bagi 3, 6, 12, … Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Tₙ = arⁿ⁻¹. Semak: 3, 6, 12, 24, 48, 96 ✓.

  1. T₆ = 3 × 2⁵ = 96
5.
Adakah 2, 4, 8, … janjang aritmetik? Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Semak beza bagi SEMUA pasangan sebutan berturutan.

  1. 8 − 4 = 4 ≠ 2: bukan janjang aritmetik
  2. Nisbah sama (2): janjang geometri

7Imbas semula

Ulang kaji kemahiran lama: Bab 3 dan Bab 4.

1.
Jisim suatu bahan reput menjadi separuh setiap 5 hari. Jisim awal 1600 g. Jisim selepas 15 hari ialah
Penyelesaian
  1. Bilangan separuh hayat = 3
  2. Jisim = 1600 × (1/2)^3 = 200 g
2.
Dengan asas 3, nilai bagi log 9 + log 3 ialah
Penyelesaian
  1. log 9 = 2; log 3 = 1
  2. Jumlah = 3
3.
Selesaikan y = 3x + 4 dan y = x².
Penyelesaian
  1. x² = 3x + 4 → x² −3x − 4 = 0
  2. x = −1, 4
