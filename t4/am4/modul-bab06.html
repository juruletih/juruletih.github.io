2Contoh berpandu

Baca setiap langkah bersama sebabnya. Tutup skrin dan cuba tulis semula sendiri.

Contoh A: y = ax² + bx

Graf y/x melawan x ialah garis lurus yang melalui (1, 5) dan (3, 9). Cari a dan b, dan tulis persamaan y dalam sebutan x.

  1. y = ax² + bx → y/x = ax + bBahagi dengan x supaya bentuk Y = mX + c.
  2. Y = y/x, X = x, m = a, c = bPadankan dengan Y = mX + c.
  3. m = (9 − 5)/(3 − 1) = 2, jadi a = 2Kecerunan.
  4. 5 = 2(1) + c, c = 3, jadi b = 3Pintasan.
  5. y = 2x² + 3xTulis semula hubungan asal.

Semak: x = 3, y = 18 + 9 = 27, y/x = 9 ✓

Contoh B: y = abˣ

Graf log₁₀ y melawan x ialah garis lurus dengan kecerunan 0.477 dan pintasan-Y 0.301. Cari a dan b.

  1. log₁₀ y = log₁₀ a + x log₁₀ bAmbil log kedua-dua belah.
  2. Y = log₁₀ y, X = x, m = log₁₀ b, c = log₁₀ aPadankan.
  3. log₁₀ a = 0.301 → a = antilog 0.301 = 2.00Pintasan.
  4. log₁₀ b = 0.477 → b = antilog 0.477 = 3.00Kecerunan.

3Contoh separa siap

Langkah bergaris putus-putus kosong. Tulis langkah itu di kertas dahulu, kemudian tekan "Lihat langkah". Bilangan langkah kosong bertambah.

1. Garis lurus Y melawan X melalui (2, 7) dan (5, 13). Cari persamaan garis. 1 langkah kosong

  1. m = (13 − 7)/(5 − 2) = 2Kecerunan.
  2. 7 = 2(2) + c, c = 3Gantikan satu titik.
  3. Lihat langkahY = 2X + 3Persamaan.

2. Tukarkan y = a/x + b kepada bentuk linear. 2 langkah kosong

  1. y = a(1/x) + bTulis 1/x sebagai satu pemboleh ubah.
  2. Lihat langkahY = y, X = 1/xPilih paksi.
  3. Lihat langkahKecerunan = a, pintasan-Y = bPadankan.

3. Tukarkan y = kxⁿ kepada bentuk linear. 2 langkah kosong

  1. log₁₀ y = log₁₀ k + n log₁₀ xAmbil log.
  2. Lihat langkahY = log₁₀ y, X = log₁₀ xPilih paksi.
  3. Lihat langkahKecerunan = n, pintasan-Y = log₁₀ kPadankan.

4. Graf y/x melawan x mempunyai kecerunan 2 dan pintasan-Y 3. Cari y apabila x = 4. 3 langkah kosong

  1. y/x = 2x + 3Persamaan garis.
  2. Lihat langkahy = 2x² + 3xDarab dengan x.
  3. Lihat langkahx = 4: y = 32 + 12Gantikan.
  4. Lihat langkah= 44Kira.
