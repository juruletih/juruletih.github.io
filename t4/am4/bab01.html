Nota

1.1 Fungsi

Fungsi ialah hubungan yang mana setiap objek dalam domain mempunyai tepat satu imej. Ujian garis mencancang: setiap garis mencancang memotong graf sekali sahaja.

Tatatanda: f : x → 2x + 3 atau f(x) = 2x + 3. Domain = set objek; kodomain = set imej yang mungkin; julat = set imej sebenar.

Fungsi nilai mutlak f(x) = |x − a|: nilai sentiasa ≥ 0. |2x − 5| = 3 → 2x − 5 = 3 atau 2x − 5 = −3 → x = 4 atau x = 1.

Untuk julat bagi suatu domain terhad, nilaikan fungsi di hujung domain dan di titik pusingan (cth. titik minimum fungsi nilai mutlak).

1.2 Fungsi Gubahan

gf(x) = g[f(x)]: f dilakukan dahulu, kemudian g. Secara amnya fg ≠ gf. f²(x) = ff(x).

Contoh: f(x) = 2x + 1, g(x) = x² → gf(x) = (2x + 1)², fg(x) = 2x² + 1, f²(x) = 4x + 3.

Mencari fungsi yang tidak diketahui: jika fg diberi dan f diketahui, gantikan g(x) ke dalam f dan selesaikan. Jika gf diberi, gantikan u = f(x) dan ungkapkan x dalam u.

1.3 Fungsi Songsang

f⁻¹ wujud hanya jika f ialah fungsi satu dengan satu (ujian garis mengufuk).

Jika f(a) = b, maka f⁻¹(b) = a. ff⁻¹(x) = f⁻¹f(x) = x.

Graf f dan f⁻¹ ialah pantulan antara satu sama lain pada garis y = x.

Langkah: tulis y = f(x), ungkapkan x dalam sebutan y, kemudian tukar y kepada x. Cth. f(x) = 2x + 5 → f⁻¹(x) = (x − 5)/2.

Latihan

Cuba dahulu di kertas. Tekan "Semak jawapan" selepas anda cuba.

  1. f : x → 2x + 3. Cari imej bagi 4 dan objek yang imejnya 9.1.1.3 / TP2
    Semak jawapan
    11; 3
  2. f(x) = |2x − 5|. Cari nilai x apabila f(x) = 3.1.1.3 / TP3
    Semak jawapan
    x = 1, 4
  3. Cari julat bagi f(x) = |x − 2| untuk domain −1 ≤ x ≤ 4.1.1.2 / TP4
    Semak jawapan
    0 ≤ f(x) ≤ 3
  4. f(x) = 2x + 1 dan g(x) = x². Cari gf(x), fg(x) dan f²(x).1.2.2 / TP3
    Semak jawapan
    (2x + 1)²; 2x² + 1; 4x + 3
  5. Bagi soalan 4, selesaikan gf(x) = 25.1.2.3 / TP4
    Semak jawapan
    x = 2, −3
  6. f(x) = x + 3 dan gf(x) = 2x + 7. Cari g(x).1.2.4 / TP5
    Semak jawapan
    g(x) = 2x + 1
  7. f(x) = 3x − 4. Cari f⁻¹(x) dan f⁻¹(5).1.3.3 / TP3
    Semak jawapan
    (x + 4)/3; 3
  8. f(x) = (x + 1)/(x − 2), x ≠ 2. Cari f⁻¹(x).1.3.3 / TP4
    Semak jawapan
    (2x + 1)/(x − 1), x ≠ 1
  9. (KBAT) Kedai memberi diskaun RM10 [f(x) = x − 10] dan potongan 20% [g(x) = 0.8x]. Bagi harga RM100, bandingkan fg(100) dan gf(100). Tertib manakah lebih menguntungkan pembeli?1.2.5 / TP6
    Semak jawapan
    fg(100) = 70, gf(100) = 72; fg
  10. (KBAT) Tunjukkan bahawa h(x) = (2x + 3)/(x − 2) ialah songsangan bagi dirinya sendiri.1.3.2 / TP6
    Semak jawapan
    h⁻¹(x) = (2x + 3)/(x − 2) = h(x)
