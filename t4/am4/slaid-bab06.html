6.1 Hubungan Linear dan Tak Linear

Hubungan linear: graf garis lurus Y = mX + c. Hubungan tak linear: graf lengkung.

Garis lurus penyuaian terbaik: melalui sebanyak mungkin titik, dengan titik-titik lain bertaburan seimbang di kedua-dua belah garis.

Daripada garis: kecerunan m dan pintasan-Y c; nilai yang tidak diketahui boleh dianggar daripada graf atau persamaan.

6.2 Hukum Linear dan Hubungan Tak Linear

Tukarkan persamaan tak linear kepada bentuk Y = mX + c:

y = ax² + b → Y = y, X = x², m = a, c = b.

y = a/x + b → Y = y, X = 1/x.

y = px + q/x → xy = px² + q: Y = xy, X = x².

y = abˣ → log y = (log b)x + log a: Y = log y, X = x.

y = kxⁿ → log y = n log x + log k: Y = log y, X = log x.

6.3 Aplikasi Hukum Linear

Langkah: (1) tentukan Y dan X; (2) bina jadual nilai baharu; (3) plot dan lukis garis penyuaian terbaik; (4) cari m dan c; (5) tentukan pemalar asal; (6) jawab soalan.

Cth. T = k√L (bandul): plot T² melawan L, kecerunan = k².
