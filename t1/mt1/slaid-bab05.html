5.1 Persamaan Linear dalam Satu Pemboleh Ubah (1/3)

Persamaan linear dalam satu pemboleh ubah mempunyai tanda sama dengan (=), satu pemboleh ubah sahaja, dan kuasa pemboleh ubah itu ialah 1. Contoh: 3x + 5 = 17. Bukan contoh: x² = 9 (kuasa 2), x + y = 5 (dua pemboleh ubah), 2x + 3 (tiada tanda =).

Membentuk persamaan: "Tiga kali suatu nombor ditambah 4 ialah 25" → 3n + 4 = 25.

5.1 Persamaan Linear dalam Satu Pemboleh Ubah (2/3)

Menyelesaikan: buat operasi yang sama pada kedua-dua belah supaya pemboleh ubah tinggal sendiri. Fikir seperti neraca: apa yang dibuat pada satu piring mesti dibuat pada piring lain.

Contoh 1. 3x + 5 = 17 → 3x = 12 (tolak 5) → x = 4 (bahagi 3). Semak: 3(4) + 5 = 17 ✓

Contoh 2. 5(y − 2) = 2y + 8 → 5y − 10 = 2y + 8 → 3y = 18 → y = 6.

Contoh 3. x/4 − 3 = 2 → x/4 = 5 → x = 20.

5.1 Persamaan Linear dalam Satu Pemboleh Ubah (3/3)

Masalah: Harga sebuah beg ialah RM15 lebih daripada harga sebuah kasut. Jumlah harga ialah RM95. Biar kasut = RMk: k + (k + 15) = 95 → 2k = 80 → k = 40. Kasut RM40, beg RM55.

5.2 Ketaksamaan Linear dalam Satu Pemboleh Ubah (1/4)

Simbol: > lebih daripada, < kurang daripada, ≥ lebih daripada atau sama dengan, ≤ kurang daripada atau sama dengan.

Garis nombor: bulatan kosong (○) untuk > atau < (nilai itu tidak termasuk); bulatan penuh (●) untuk ≥ atau ≤ (nilai itu termasuk). x > 2: ○ pada 2 dan anak panah ke kanan. x ≤ −1: ● pada −1 dan anak panah ke kiri.

5.2 Ketaksamaan Linear dalam Satu Pemboleh Ubah (2/4)

Pernyataan umum (a < b): (i) b > a; (ii) jika juga b < c, maka a < c; (iii) −a > −b; (iv) 1/a > 1/b jika a dan b sama tanda; (v) b − a > 0; (vi) ca < cb jika c > 0.

Operasi pada ketaksamaan: tambah, tolak, darab atau bahagi dengan nombor positif → simbol kekal. Darab atau bahagi dengan nombor negatif → simbol diterbalikkan. Contoh: 3 < 5, darab −2 → −6 > −10.

5.2 Ketaksamaan Linear dalam Satu Pemboleh Ubah (3/4)

Contoh 4. 2x − 3 ≥ 7 → 2x ≥ 10 → x ≥ 5.

Contoh 5. 4 − 3x > 13 → −3x > 9 → bahagi −3, terbalikkan simbol → x < −3.

Ketaksamaan linear serentak: selesaikan setiap satu, kemudian cari nilai sepunya. x + 2 > 0 dan 3x ≤ 12 → x > −2 dan x ≤ 4 → −2 < x ≤ 4. Integer yang memuaskan: −1, 0, 1, 2, 3, 4.

5.2 Ketaksamaan Linear dalam Satu Pemboleh Ubah (4/4)

Masalah: Tiket bas RM3 dan Siti ada RM20. Biar t = bilangan tiket: 3t ≤ 20 → t ≤ 6.67. Bilangan tiket maksimum = 6.
