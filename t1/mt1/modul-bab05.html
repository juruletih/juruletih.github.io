2Contoh berpandu

Baca setiap langkah bersama sebabnya. Tutup skrin dan cuba tulis semula sendiri.

Contoh A: persamaan dengan pemboleh ubah di kedua-dua belah

Selesaikan 4(x − 3) = x + 9.

  1. 4x − 12 = x + 9Kembangkan kurungan.
  2. 4x − x = 9 + 12Kumpul sebutan x di kiri, nombor di kanan. Tanda berubah apabila sebutan dipindahkan.
  3. 3x = 21Permudahkan.
  4. x = 7Bahagi kedua-dua belah dengan 3.

Semak: 4(7 − 3) = 16 dan 7 + 9 = 16 ✓

Contoh B: ketaksamaan dengan pekali negatif

Selesaikan 5 − 2x ≥ 11.

  1. −2x ≥ 11 − 5Tolak 5 pada kedua-dua belah.
  2. −2x ≥ 6Permudahkan.
  3. x ≤ −3Bahagi dengan −2. Bahagi dengan nombor negatif → terbalikkan simbol ≥ menjadi ≤.

Semak dengan x = −4 (memuaskan x ≤ −3): 5 − 2(−4) = 13 ≥ 11 ✓

Contoh C: ketaksamaan serentak

Selesaikan x + 4 > 2 dan 3x − 1 ≤ 8. Senaraikan integer yang memuaskan.

  1. x + 4 > 2 → x > −2Selesaikan ketaksamaan pertama.
  2. 3x − 1 ≤ 8 → 3x ≤ 9 → x ≤ 3Selesaikan ketaksamaan kedua.
  3. −2 < x ≤ 3Gabungkan: nilai yang memuaskan kedua-duanya. Lukis kedua-duanya pada garis nombor dan cari bahagian bertindih.
  4. Integer: −1, 0, 1, 2, 3−2 tidak termasuk (<), 3 termasuk (≤).

3Contoh separa siap

Langkah bergaris putus-putus kosong. Tulis langkah itu di kertas dahulu, kemudian tekan "Lihat langkah". Bilangan langkah kosong bertambah.

1. Selesaikan 3x + 7 = 22. 1 langkah kosong

  1. 3x = 22 − 7Tolak 7.
  2. 3x = 15Permudahkan.
  3. Lihat langkahx = 5Bahagi 3.

2. Selesaikan y/3 + 4 = 10. 2 langkah kosong

  1. y/3 = 6Tolak 4.
  2. Lihat langkahy = 6 × 3Darab 3.
  3. Lihat langkahy = 18Kira.

3. Selesaikan 7 − 3k < 19. 2 langkah kosong

  1. −3k < 12Tolak 7.
  2. Lihat langkahBahagi dengan −3, terbalikkan simbolPekali negatif.
  3. Lihat langkahk > −4Jawapan.

4. Harga sebuah pen ialah RM4. Amir ada RM30. Berapakah bilangan maksimum pen yang boleh dibeli? 3 langkah kosong

  1. Biar p = bilangan penTakrif pemboleh ubah.
  2. Lihat langkah4p ≤ 30"Ada RM30" → jumlah harga tidak boleh melebihi 30.
  3. Lihat langkahp ≤ 7.5Bahagi 4.
  4. Lihat langkahMaksimum 7 batang penBilangan pen mesti integer.

5Cari silap

Kesilapan ini paling kerap berlaku dalam bab ini. Mengenal pasti silap orang lain membantu anda mengelakkannya.

1.
Selesaikan x + 8 = 3. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Untuk menghapuskan +8, tolak 8 daripada kedua-dua belah. Semak: −5 + 8 = 3 ✓

  1. x = 3 − 8
  2. x = −5
2.
Selesaikan 4x = 20. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

4x bermaksud 4 × x. Operasi songsang bagi darab ialah bahagi.

  1. x = 20 ÷ 4
  2. x = 5
3.
Selesaikan −2x < 8. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Bahagi dengan nombor negatif mesti menterbalikkan simbol. Semak dengan x = 0: −2(0) = 0 < 8 ✓, dan 0 > −4 ✓.

  1. x > 8 ÷ (−2)
  2. x > −4
4.
Wakilkan x ≥ 2 pada garis nombor. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

≥ dan ≤ termasuk nilai itu, jadi bulatan penuh. Bulatan kosong untuk > dan <.

  1. Bulatan penuh pada 2 (2 termasuk)
  2. Anak panah ke kanan
5.
Selesaikan 2(x + 3) = 14. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

2 mesti didarab dengan setiap sebutan dalam kurungan: 2 × 3 = 6.

  1. 2x + 6 = 14
  2. 2x = 8
  3. x = 4
