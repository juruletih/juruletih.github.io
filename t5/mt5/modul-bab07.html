2Contoh berpandu

Baca setiap langkah bersama sebabnya. Tutup skrin dan cuba tulis semula sendiri.

Contoh A: min data terkumpul

Kelas 1–5 (f = 4), 6–10 (f = 6), 11–15 (f = 10). Hitung min.

  1. Titik tengah x: 3, 8, 13Setiap kelas diwakili titik tengahnya.
  2. fx: 4(3) = 12, 6(8) = 48, 10(13) = 130Darab kekerapan dengan titik tengah.
  3. Σfx = 190, Σf = 20Jumlahkan.
  4. Min = 190 ÷ 20 = 9.5Min = Σfx ÷ Σf.

Contoh B: sisihan piawai data terkumpul

Bagi data yang sama, hitung sisihan piawai.

  1. fx²: 4(9) = 36, 6(64) = 384, 10(169) = 1 690Kuasa duakan titik tengah, kemudian darab f.
  2. Σfx² = 2 110Jumlahkan.
  3. σ² = Σfx²/Σf − (min)² = 2 110/20 − 9.5²Rumus varians.
  4. σ² = 105.5 − 90.25 = 15.25Kira.
  5. σ = √15.25 = 3.91Punca kuasa dua.

3Contoh separa siap

Langkah bergaris putus-putus kosong. Tulis langkah itu di kertas dahulu, kemudian tekan "Lihat langkah". Bilangan langkah kosong bertambah.

1. Bagi kelas 20–24, cari sempadan bawah, sempadan atas dan saiz selang kelas. 1 langkah kosong

  1. Sempadan bawah = 19.5Had bawah − 0.5.
  2. Sempadan atas = 24.5Had atas + 0.5.
  3. Lihat langkahSaiz selang kelas = 24.5 − 19.5 = 5Sempadan atas − sempadan bawah.

2. Kekerapan empat kelas ialah 3, 5, 8, 4. Bina kekerapan longgokan. 2 langkah kosong

  1. Kekerapan longgokan pertama = 3Sama dengan kekerapan pertama.
  2. 3 + 5 = 8Tambah kekerapan seterusnya.
  3. Lihat langkah8 + 8 = 16Teruskan.
  4. Lihat langkah16 + 4 = 20Nilai akhir = jumlah kekerapan.

3. Ogif dibina bagi 40 murid. Terangkan cara mencari julat antara kuartil. 2 langkah kosong

  1. Q₁ pada kekerapan longgokan ¼ × 40 = 10Kedudukan Q₁.
  2. Lihat langkahQ₃ pada kekerapan longgokan ¾ × 40 = 30Kedudukan Q₃.
  3. Lihat langkahBaca nilai pada paksi mengufuk; JAK = Q₃ − Q₁Ogif memberi nilai data pada paksi mengufuk.

4. Kelas 10–19 (f = 2), 20–29 (f = 5), 30–39 (f = 3). Hitung min. 3 langkah kosong

  1. Titik tengah: 14.5, 24.5, 34.5Titik tengah.
  2. Lihat langkahΣfx = 29 + 122.5 + 103.5 = 255Jumlah fx.
  3. Lihat langkahΣf = 10Jumlah kekerapan.
  4. Lihat langkahMin = 255 ÷ 10 = 25.5Bahagi.

Kesilapan ini paling kerap berlaku dalam bab ini. Mengenal pasti silap orang lain membantu anda mengelakkannya.

1.
Kelas 1–5 (f = 4), 6–10 (f = 6), 11–15 (f = 10). Hitung min. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Data terkumpul diwakili oleh titik tengah kelas, bukan had atas.

  1. x = titik tengah: 3, 8, 13
  2. Min = 190 ÷ 20 = 9.5
2.
Σfx = 190 bagi 3 kelas dengan Σf = 20. Hitung min. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

Bahagi dengan jumlah kekerapan, bukan bilangan kelas. Semak: min mesti berada dalam julat data (1 hingga 15).

  1. Min = 190 ÷ Σf = 190 ÷ 20 = 9.5
3.
Terangkan cara membina ogif. Seorang murid menulis jalan kerja di bawah. Pilih langkah pertama yang salah.
Pembetulan

  1. Plot kekerapan longgokan melawan sempadan atas
4.
