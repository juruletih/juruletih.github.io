Nota

2.1 Matriks

Matriks ialah susunan nombor dalam baris dan lajur. Dalam bahan ini, [a, b; c, d] bermaksud baris pertama a, b dan baris kedua c, d.

Peringkat m × n: m baris, n lajur (dibaca "m dengan n"). Unsur aij terletak pada baris ke-i, lajur ke-j.

Jenis: matriks baris (1 × n), matriks lajur (m × 1), matriks segi empat sama (m = n), matriks segi empat tepat.

Matriks sama: peringkat sama dan setiap unsur sepadan sama. Cth. [x, 4; 3, y] = [7, 4; 3, −2] → x = 7, y = −2.

2.2 Operasi Asas Matriks

Tambah/tolak: hanya bagi matriks yang sama peringkat; tambah/tolak unsur sepadan. Matriks sifar O: A + O = A.

Pendaraban skalar: kA, darab setiap unsur dengan k (nA = A + A + … + A).

Darab dua matriks AB wujud jika bilangan lajur A = bilangan baris B. (m × n)(n × p) → m × p. Secara amnya AB ≠ BA.

Matriks identiti I = [1, 0; 0, 1]: AI = IA = A.

Matriks songsang bagi A = [a, b; c, d]: A⁻¹ = 1/(ad − bc) × [d, −b; −c, a]. Penentu = ad − bc. Jika penentu = 0, A⁻¹ tidak wujud.

Persamaan serentak ax + by = h, cx + dy = k: tulis [a, b; c, d][x; y] = [h; k], maka [x; y] = A⁻¹[h; k].

Contoh. 2x + y = 7, x − y = 2: penentu = −3; [x; y] = −1/3 [−1, −1; −1, 2][7; 2] = [3; 1].

Latihan

Cuba dahulu di kertas. Tekan "Semak jawapan" selepas anda cuba.

  1. Nyatakan peringkat matriks [3, 5, −1; 2, 0, 4] dan unsur a₂₃.2.1.2 / TP1
    Semak jawapan
    2 × 3; a₂₃ = 4
  2. Kedai A menjual 20 nasi lemak dan 15 roti; kedai B menjual 12 nasi lemak dan 18 roti. Wakilkan dalam matriks 2 × 2 (baris = kedai).2.1.1 / TP2
    Semak jawapan
    [20, 15; 12, 18]
  3. Diberi [x + y, 3; 2, x − y] = [10, 3; 2, 4]. Cari x dan y.2.1.3 / TP3
    Semak jawapan
    x = 7, y = 3
  4. Hitung [2, 1; 3, 4] + [1, −1; 0, 2] dan 3[2, −1; 0, 4].2.2.1 / TP2
    Semak jawapan
    [3, 0; 3, 6]; [6, −3; 0, 12]
  5. Hitung [1, 2; 3, 4][2; 1].2.2.3 / TP3
    Semak jawapan
    [4; 10]
  6. Tunjukkan bahawa AI = A bagi A = [2, 5; 1, 3].2.2.4 / TP3
    Semak jawapan
    [2, 5; 1, 3][1, 0; 0, 1] = [2, 5; 1, 3]
  7. Cari songsang bagi [4, 3; 1, 1].2.2.5 / TP4
    Semak jawapan
    [1, −3; −1, 4]
  8. Terangkan mengapa [6, 3; 4, 2] tiada songsang.2.2.5 / TP4
    Semak jawapan
    Penentu = 12 − 12 = 0
  9. Selesaikan dengan kaedah matriks: 2x + y = 7, x − y = 2.2.2.6 / TP5
    Semak jawapan
    x = 3, y = 1
  10. (KBAT) Ali membeli 2 pen dan 3 buku dengan RM19; Ben membeli 4 pen dan 1 buku dengan RM13. Gunakan kaedah matriks untuk mencari harga sebatang pen dan sebuah buku.2.2.7 / TP6
    Semak jawapan
    Pen RM2, buku RM5
