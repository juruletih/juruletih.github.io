2Contoh berpandu

Baca setiap langkah bersama sebabnya. Tutup skrin dan cuba tulis semula sendiri.

Contoh A: taburan binomial

X ~ B(5, 0.3). Cari P(X = 2).

  1. n = 5, p = 0.3, q = 1 − 0.3 = 0.7Kenal pasti parameter.
  2. P(X = r) = ⁿCᵣ pʳ qⁿ⁻ʳRumus binomial.
  3. P(X = 2) = ⁵C₂(0.3)²(0.7)³Gantikan: 2 berjaya, 3 gagal.
  4. = 10 × 0.09 × 0.343 = 0.3087Kira.

Contoh B: taburan normal

X ~ N(50, 5²). Cari P(X > 60).

  1. μ = 50, σ = 5Parameter: N(μ, σ²).
  2. z = (60 − 50)/5 = 2Piawaikan.
  3. P(X > 60) = P(Z > 2)Tukar kepada Z.
  4. = 0.0228Baca jadual taburan normal piawai.

Semak: 60 jauh di atas min, jadi kebarangkalian kecil ✓

3Contoh separa siap

Langkah bergaris putus-putus kosong. Tulis langkah itu di kertas dahulu, kemudian tekan "Lihat langkah". Bilangan langkah kosong bertambah.

1. X ~ B(20, 0.4). Cari min, varians dan sisihan piawai. 1 langkah kosong

  1. Min = np = 20 × 0.4 = 8Rumus min.
  2. Varians = npq = 8 × 0.6 = 4.8Rumus varians.
  3. Lihat langkahσ = √4.8 = 2.191Punca kuasa dua.

2. X ~ B(4, 0.2). Cari P(X = 0). 2 langkah kosong

  1. P(X = 0) = ⁴C₀(0.2)⁰(0.8)⁴Rumus.
  2. Lihat langkah= 1 × 1 × 0.4096Kira setiap faktor.
  3. Lihat langkah= 0.4096Jawapan.

3. X ~ N(40, 4²). Cari skor-z bagi x = 46. 2 langkah kosong

  1. z = (x − μ)/σRumus.
  2. Lihat langkah= (46 − 40)/4Gantikan.
  3. Lihat langkah= 1.5Kira.

4. X ~ B(3, 0.5). Cari P(X ≥ 1). 3 langkah kosong

  1. P(X ≥ 1) = 1 − P(X = 0)Pelengkap lebih mudah.
  2. Lihat langkahP(X = 0) = (0.5)³ = 0.125Kira.
  3. Lihat langkahP(X ≥ 1) = 1 − 0.125Tolak.
  4. Lihat langkah= 0.875Jawapan.

2.
