Bab 7: Pengaturcaraan Linear

Matematik Tambahan Tingkatan 5 · Nota, latihan dan kuiz

Selepas bab ini, anda boleh

  • membentuk model matematik (kekangan dan fungsi objektif) bagi situasi dan melorek rantau tersaur (SP 7.1.1)
  • menyelesaikan masalah pengaturcaraan linear dengan kaedah graf (SP 7.2.1)

Slaid

Buka slaid

Slaid penuh skrin. Guna anak panah atau leret jari. Boleh dicetak.

Nota

7.1 Model Pengaturcaraan Linear

Langkah: (1) takrif pemboleh ubah x dan y; (2) tulis kekangan sebagai ketaksamaan linear; (3) tulis fungsi objektif k = ax + by.

Terjemahan: "tidak melebihi" ≤; "sekurang-kurangnya" ≥; "y melebihi x sekurang-kurangnya 5" → y − x ≥ 5; "x tidak melebihi dua kali y" → x ≤ 2y.

Biasanya x ≥ 0 dan y ≥ 0. Rantau tersaur ialah rantau yang memuaskan semua kekangan.

7.2 Aplikasi

Nilai maksimum atau minimum fungsi objektif berlaku pada bucu rantau tersaur.

Kaedah garis objektif: lukis ax + by = k, gerakkan selari sehingga titik terakhir (maksimum) atau pertama (minimum) dalam rantau.

Jika jawapan mesti integer (bilangan barang), pilih titik integer dalam rantau.

Latihan

Cuba dahulu di kertas. Tekan "Semak jawapan" selepas anda cuba.

  1. Tulis ketaksamaan: "Jumlah x dan y sekurang-kurangnya 10."7.1.1 / TP2
    Semak jawapan
    x + y ≥ 10
  2. Tulis ketaksamaan: "Bilangan y melebihi x sekurang-kurangnya 5."7.1.1 / TP3
    Semak jawapan
    y − x ≥ 5
  3. Kek memerlukan 2 jam dan roti 1 jam; masa maksimum 40 jam. Untung kek RM4, roti RM3. Tulis kekangan masa dan fungsi objektif.7.1.1 / TP3
    Semak jawapan
    2x + y ≤ 40; P = 4x + 3y
  4. Cari titik persilangan x + y = 10 dan 2x + y = 16.7.2.1 / TP2
    Semak jawapan
    (6, 4)
  5. Dengan kekangan x + y ≤ 10, 2x + y ≤ 16, x ≥ 0, y ≥ 0, cari nilai maksimum P = 3x + 2y.7.2.1 / TP3
    Semak jawapan
    26 pada (6, 4)
  6. Dengan kekangan yang sama, cari nilai maksimum P = x + 2y.7.2.1 / TP3
    Semak jawapan
    20 pada (0, 10)
  7. Dengan kekangan x + y ≥ 6, x + 3y ≥ 12, x ≥ 0, y ≥ 0, cari nilai minimum C = 2x + 3y.7.2.1 / TP4
    Semak jawapan
    15 pada (3, 3)
  8. Jika kekangan y ≥ x ditambah kepada x + y ≤ 10, 2x + y ≤ 16, cari nilai maksimum P = 3x + 2y.7.2.1 / TP5
    Semak jawapan
    25 pada (5, 5)
  9. Produk A memerlukan 3 kg bahan dan B 2 kg; bahan tidak melebihi 60 kg; bilangan A sekurang-kurangnya separuh bilangan B. Tulis kekangan.7.1.1 / TP5
    Semak jawapan
    3x + 2y ≤ 60; 2x ≥ y
  10. (KBAT) Kilang menghasilkan x unit A (untung RM40) dan y unit B (untung RM30). Masa mesin 2x + y ≤ 100 jam dan masa buruh x + 2y ≤ 80 jam. Cari untung maksimum.7.2.1 / TP6
    Semak jawapan
    RM2 200 pada (40, 20)
