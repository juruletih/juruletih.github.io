3.1 Pengamiran sebagai Songsangan Pembezaan

Jika d/dx[F(x)] = f(x), maka ∫ f(x) dx = F(x) + c; c ialah pemalar pengamiran.

3.2 Kamiran Tak Tentu

∫ axⁿ dx = axⁿ⁺¹/(n + 1) + c, n ≠ −1.

∫ (ax + b)ⁿ dx = (ax + b)ⁿ⁺¹/[a(n + 1)] + c, n ≠ −1.

Persamaan lengkung: kamirkan dy/dx, kemudian gantikan titik yang diberi untuk mencari c.

3.3 Kamiran Tentu (1/2)

∫ₐᵇ f(x) dx = F(b) − F(a), dengan a had bawah dan b had atas.

Menukar had bawah dan had atas menukar tanda kamiran. Bagi a < b < c, kamiran dari a ke c = kamiran dari a ke b + kamiran dari b ke c.

Luas di bawah lengkung = ∫ₐᵇ y dx (paksi-x) atau ∫ₐᵇ x dy (paksi-y). Nilai negatif bermaksud rantau di bawah paksi-x; luas ialah nilai mutlaknya.

Luas antara dua lengkung = ∫ₐᵇ (y atas − y bawah) dx.

3.3 Kamiran Tentu (2/2)

Isi padu janaan (kisaran 360°): paksi-x: π∫ₐᵇ y² dx; paksi-y: π∫ₐᵇ x² dy.

3.4 Aplikasi Pengamiran

Kadar perubahan → kamirkan untuk mendapat jumlah perubahan (cth. isi padu air, kos, jarak).

Latihan 1 daripada 103.2.2 / TP2

Cari ∫ (6x² − 4x + 3) dx.

2x³ − 2x² + 3x + c

Latihan 2 daripada 103.2.3 / TP3

Cari ∫ (2x + 3)⁴ dx.

(2x + 3)⁵/10 + c

Latihan 3 daripada 103.2.4 / TP4

Kecerunan lengkung ialah 6x − 2 dan lengkung melalui (1, 5). Cari persamaan lengkung.

y = 3x² − 2x + 4

Latihan 4 daripada 103.1.1 / TP5

Diberi d/dx[(x² + 1)³] = 6x(x² + 1)², cari ∫ x(x² + 1)² dx.

(x² + 1)³/6 + c

Latihan 5 daripada 103.3.1 / TP2

Nilaikan ∫₀² (3x² + 1) dx.

10

Latihan 6 daripada 103.3.3 / TP4

Cari luas rantau yang dibatasi y = 4 − x² dan paksi-x.

32/3 unit²

Latihan 7 daripada 103.3.3 / TP5

Cari luas rantau di antara y = x² dan y = 2x.

4/3 unit²

Latihan 8 daripada 103.3.5 / TP4

Rantau di bawah y = √x, 0 ≤ x ≤ 4, dikisarkan 360° pada paksi-x. Cari isi padu janaan.

8π unit³

Latihan 9 daripada 103.4 / TP4

Kos marginal dC/dx = 4x + 10 (RM) dan kos tetap RM50. Cari jumlah kos bagi 10 unit.

RM350

Latihan 10 daripada 103.4 / TP6

(KBAT) Mangkuk dibentuk dengan mengisarkan lengkung y = x², 0 ≤ y ≤ 4, 360° pada paksi-y. Cari isi padu mangkuk.

8π unit³
