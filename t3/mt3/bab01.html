Bab 1: Indeks

Matematik Tingkatan 3 · Nota, latihan dan kuiz

Selepas bab ini, anda boleh

  • mewakilkan pendaraban berulang dalam bentuk indeks dan sebaliknya (SP 1.1.1, 1.1.2)
  • mengaitkan dan menggunakan hukum indeks: pendaraban, pembahagian, kuasa, indeks sifar, negatif dan pecahan (SP 1.2.1–1.2.6)
  • menyelesaikan masalah yang melibatkan hukum indeks (SP 1.2.7)

Slaid

Buka slaid

Slaid penuh skrin. Guna anak panah atau leret jari. Boleh dicetak.

Nota

1.1 Tatatanda Indeks

aⁿ bermaksud a didarab dengan dirinya sendiri sebanyak n kali. a ialah asas, n ialah indeks.

Contoh 1. 3 × 3 × 3 × 3 = 3⁴ = 81.   64 = 2⁶ = 4³ = 8².

Awas: (−2)⁴ = 16 tetapi −2⁴ = −16. Kurungan menentukan asas.

1.2 Hukum Indeks

HukumContoh
aᵐ × aⁿ = aᵐ⁺ⁿ2³ × 2⁴ = 2⁷
aᵐ ÷ aⁿ = aᵐ⁻ⁿ5⁶ ÷ 5² = 5⁴
(aᵐ)ⁿ = aᵐⁿ(3²)⁴ = 3⁸
(ab)ⁿ = aⁿbⁿ(2x)³ = 8x³
a⁰ = 1 (a ≠ 0)7⁰ = 1
a⁻ⁿ = 1/aⁿ2⁻³ = 1/8
a^(1/n) = ⁿ√a27^(1/3) = 3
a^(m/n) = (ⁿ√a)ᵐ8^(2/3) = 2² = 4

Hukum pendaraban dan pembahagian hanya boleh digunakan jika asas sama.

Contoh 2. Selesaikan 2ˣ⁺¹ = 32 → 2ˣ⁺¹ = 2⁵ → x + 1 = 5 → x = 4.

Awas miskonsepsi: 2³ × 2⁴ ≠ 4⁷ (asas tidak didarab) dan a⁻² ≠ −a².

Latihan

Cuba dahulu di kertas. Tekan "Semak jawapan" selepas anda cuba.

  1. Tulis 5 × 5 × 5 × 5 × 5 dalam bentuk indeks.1.1.1 / TP1
    Semak jawapan
    5⁵
  2. Tulis 81 sebagai kuasa bagi 3.1.1.2 / TP2
    Semak jawapan
    3⁴
  3. Permudahkan 2³ × 2⁵ ÷ 2⁴.1.2.6 / TP2
    Semak jawapan
    2⁴ = 16
  4. Permudahkan (3a²b)³.1.2.3 / TP3
    Semak jawapan
    27a⁶b³
  5. Nilaikan 4⁻² dan 16^(3/4).1.2.5 / TP3
    Semak jawapan
    1/16 dan 8
  6. Permudahkan (a⁵b³ × a²b) ÷ a⁴b².1.2.6 / TP4
    Semak jawapan
    a³b²
  7. Selesaikan 3²ˣ⁻¹ = 27.1.2.7 / TP4
    Semak jawapan
    2x − 1 = 3 → x = 2
  8. Selesaikan 4ˣ = 8ˣ⁻¹.1.2.7 / TP5
    Semak jawapan
    2²ˣ = 2³ˣ⁻³ → x = 3
  9. (KBAT) Bakteria berganda setiap jam. Bermula dengan 500 bakteria, selepas berapa jam bilangannya menjadi 32 000?1.2.7 / TP5
    Semak jawapan
    500 × 2ⁿ = 32 000 → 2ⁿ = 64 → n = 6 jam
  10. (KBAT) Tunjukkan bahawa 2¹⁰⁰ + 2¹⁰⁰ = 2¹⁰¹ dan terangkan mengapa 2¹⁰⁰ + 2¹⁰⁰ ≠ 2²⁰⁰.1.2.7 / TP6
    Semak jawapan
    2 × 2¹⁰⁰ = 2¹⁰¹. Penambahan tidak menambah indeks; hanya pendaraban yang menambah indeks.
