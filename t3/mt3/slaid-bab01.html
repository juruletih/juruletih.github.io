Bab 1: Indeks

Selepas bab ini, anda boleh

  • mewakilkan pendaraban berulang dalam bentuk indeks dan sebaliknya (SP 1.1.1, 1.1.2)
  • mengaitkan dan menggunakan hukum indeks: pendaraban, pembahagian, kuasa, indeks sifar, negatif dan pecahan (SP 1.2.1–1.2.6)
  • menyelesaikan masalah yang melibatkan hukum indeks (SP 1.2.7)

1.1 Tatatanda Indeks

aⁿ bermaksud a didarab dengan dirinya sendiri sebanyak n kali. a ialah asas, n ialah indeks.

Contoh 1. 3 × 3 × 3 × 3 = 3⁴ = 81.   64 = 2⁶ = 4³ = 8².

Awas: (−2)⁴ = 16 tetapi −2⁴ = −16. Kurungan menentukan asas.

1.2 Hukum Indeks

HukumContoh
aᵐ × aⁿ = aᵐ⁺ⁿ2³ × 2⁴ = 2⁷
aᵐ ÷ aⁿ = aᵐ⁻ⁿ5⁶ ÷ 5² = 5⁴
(aᵐ)ⁿ = aᵐⁿ(3²)⁴ = 3⁸
(ab)ⁿ = aⁿbⁿ(2x)³ = 8x³
a⁰ = 1 (a ≠ 0)7⁰ = 1
a⁻ⁿ = 1/aⁿ2⁻³ = 1/8
a^(1/n) = ⁿ√a27^(1/3) = 3
a^(m/n) = (ⁿ√a)ᵐ8^(2/3) = 2² = 4

Hukum pendaraban dan pembahagian hanya boleh digunakan jika asas sama.

Contoh 2. Selesaikan 2ˣ⁺¹ = 32 → 2ˣ⁺¹ = 2⁵ → x + 1 = 5 → x = 4.

Awas miskonsepsi: 2³ × 2⁴ ≠ 4⁷ (asas tidak didarab) dan a⁻² ≠ −a².
